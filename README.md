# 我在明朝当锦衣卫

[English](README.en.md)

![《我在明朝当锦衣卫》标题画面](public/assets/title/title-cover-desktop-v1.jpg)

一款桌面端优先的历史悬疑文字游戏。玩家扮演初入北镇抚司的锦衣卫校尉廖威达，在场景阅读、证据核验、权限请示与有限的办差选择中推进案件，并承担每一次行动带来的结果。

## 一桩案子如何推进

第一章从一间失火纸铺开始。账目、残料、失踪的人和一枚烧焦的木牌，让一桩看似普通的事故逐渐露出更深的脉络。

一次案件通常按以下节奏推进：

1. **进入场景**：阅读现场、人物与已知事实，确认眼下真正的问题。
2. **选择查办方向**：现场查访、核验材料、询问相关人，或在权限不足时向上请示。
3. **取得可核对的反馈**：新证据会注明来源与取得经过；未获准的行动也会清楚说明边界。
4. **承担即时结果**：银两、健康、人脉或证据状态的变化先在叙事中落地，再回到案件工作台。
5. **提交判断并结案**：责任判断必须建立在已经取得的事实之上，结案会给出呈报、批示与关系变化。

第一章已经具备完整的可玩闭环：现场查访、材料核验、覃保坤的权限回应、夜间保全、烧焦木牌、冯天顺重逢、责任判断，以及结案后的证据封存与资源反馈。它是后续章节的实现样板。

## 游戏原则

- 案件优先：场景、已知事实与下一项有后果的行动比常驻系统面板更重要。
- 权限有边界：廖威达能查、能提议的事，与必须请示的事会在剧情中明确区分。
- 后果需要停顿：获得证据、人物交锋、资源代价与结案都会先落在叙事里，再交还选择权。
- 桌面端阅读：以键鼠操作与长文本阅读为目标，暂不做移动端、PWA 或商店适配。

## 状态与存档

游戏只记录与案件直接相关的状态：

| 状态 | 用途 |
| --- | --- |
| 证据 | 支撑材料核验、责任判断与后续剧情反馈 |
| 银两 | 表现某些办差与保全行动的实际代价 |
| 健康 | 只在剧情明确造成身体代价时变化 |
| 人脉 | 记录已经在故事中建立、并会影响反馈的人物关系 |

存档保存在当前浏览器的 `localStorage` 中，键名为 `ming_jinyiwei.save.v3`。清除网站数据、切换浏览器或切换设备，都不会自动携带存档。

已确定的第一章规则包括：

- 覃保坤在廖威达归入其百户所后立即出现于人脉。
- 冯天顺只在第一章末重逢后加入人脉。
- 夜间“雇人守住火场残料”消耗 `5` 两银子，不减少健康。
- 旧的月份、风险与自由行动系统已经废弃，后续功能不应恢复它们。

## 从下载安装到成功开始游戏

下面按 Windows 电脑的实际操作顺序说明。macOS 和 Linux 也可以使用同样的 Git、Node.js 和 npm 命令。

### 1. 准备安装环境

请先安装以下软件：

- **Node.js 20 LTS 或更高版本**：安装 Node.js 时会同时安装 npm。
- **Git**：用于从 GitHub 下载项目。
- **桌面浏览器**：推荐最新版 Chrome 或 Edge。游戏当前以键盘和鼠标操作的桌面浏览器为目标。

安装完成后，打开 PowerShell，输入以下命令确认环境可用：

```powershell
node --version
npm --version
git --version
```

三个命令都应显示版本号。如果提示“不是内部或外部命令”，请重新安装对应软件，并重新打开 PowerShell。

### 2. 选择一种下载方式

本仓库当前为私有仓库，无论使用哪种方式，都必须先登录拥有仓库访问权限的 GitHub 账号。三种方式下载到的是同一份游戏项目，任选一种即可。

#### 推荐：下载 ZIP（最适合第一次安装和只想试玩的玩家）

1. 打开本仓库的 GitHub 页面。
2. 点击绿色的 **Code** 按钮，再点击 **Download ZIP**。
3. 下载完成后解压 ZIP 文件，例如解压到 `D:\Games\ming-jinyiwei`。
4. 打开解压后的文件夹，确认里面直接能看到 `package.json`，不要在外层重复套了一层同名文件夹。
5. 在这个文件夹空白处点击右键，选择“在终端中打开”；也可以在 PowerShell 中执行：

```powershell
cd D:\Games\ming-jinyiwei
```

ZIP 方式不需要配置 SSH，最简单；以后想获得新版本时，需要重新下载新的 ZIP 并解压，或者改用下面的 Git 方式更新。

#### HTTPS 克隆（适合希望以后用 `git pull` 更新的人）

```powershell
git clone https://github.com/77lwd/ming-jinyiwei.git
cd ming-jinyiwei
```

如果 GitHub 要求登录，请按提示完成账号验证。HTTPS 不需要配置 SSH 密钥。

#### SSH 克隆（适合已经配置 GitHub SSH 的开发者）

```powershell
git clone git@github.com:77lwd/ming-jinyiwei.git
cd ming-jinyiwei
```

如果出现 `Permission denied (publickey)`，说明本机还没有可用的 GitHub SSH 密钥；请改用 ZIP 或 HTTPS，不要继续使用这条命令。

#### GitHub Desktop（不想使用命令行时）

安装 GitHub Desktop 后，选择 **Clone a repository**，填入仓库地址并选择本地目录，完成后打开该目录即可。它与 HTTPS 克隆的效果相同。

无论选择哪种方式，后续都必须在**包含 `package.json` 的项目根目录**执行下面的安装和启动命令。不要直接双击 `index.html`，那样不会正确启动游戏。

### 3. 安装游戏依赖

在项目根目录执行：

```powershell
npm install
```

这一步会根据 `package.json` 安装游戏运行所需的 React、Vite 和其他依赖，并生成本地的 `node_modules` 文件夹。第一次安装需要一些时间；终端最后不应出现红色的安装失败信息。

### 4. 启动本地游戏服务器

继续在同一个 PowerShell 窗口执行：

```powershell
npm run dev
```

看到类似下面的提示后，说明服务器已经启动：

```text
Local:   http://localhost:5173/
```

请保持这个 PowerShell 窗口开启。关闭窗口会同时关闭本地游戏服务器。

### 5. 在浏览器中打开并开始游玩

1. 复制终端里 `Local:` 后面的完整地址，通常是 `http://localhost:5173/`。
2. 打开 Chrome 或 Edge，把地址粘贴到地址栏并回车。
3. 看到《我在明朝当锦衣卫》的标题画面后，点击开始或继续游戏。
4. 进入序章后，按照页面底部的按钮推进叙事；需要调查、询问或核验时，先阅读当前案情再选择行动。
5. 第一次进入游戏后，可打开案情记录确认当前线索和办案进度。存档会保存在当前浏览器中。

只要能看到标题画面并成功进入序章，就表示安装、依赖和本地服务器都已正常工作。图片或音频加载失败时，文字流程仍应可以继续。

### 6. 关闭、重新启动和更新

- **关闭游戏**：回到运行 `npm run dev` 的 PowerShell 窗口，按 `Ctrl + C`。
- **再次启动**：进入项目目录后重新执行 `npm run dev`，再打开终端显示的地址。
- **拉取最新更新**：先关闭正在运行的服务器，再执行 `git pull`；如果依赖发生变化，再执行一次 `npm install`，最后重新运行 `npm run dev`。

### 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `node`、`npm` 或 `git` 找不到 | 安装对应软件后关闭并重新打开 PowerShell，再检查版本命令。 |
| `git clone` 提示没有权限 | 确认 GitHub 账号已被授予仓库访问权限，并检查 SSH 密钥或改用 GitHub 的 HTTPS 克隆地址。 |
| `npm install` 失败 | 检查网络后重新执行；如果仍失败，确认当前目录是包含 `package.json` 的项目根目录。 |
| 5173 端口已被占用 | Vite 通常会自动换用下一个端口，以终端实际显示的 `Local:` 地址为准。 |
| 浏览器显示空白或旧页面 | 确认 PowerShell 中的服务器仍在运行，刷新页面；仍异常时按 `Ctrl + C` 停止后重新执行 `npm run dev`。 |
| 游戏能打开但没有存档 | 存档只保存在当前浏览器的 `localStorage`；清除网站数据、换浏览器或换设备不会自动带上原存档。 |

如果需要检查项目是否能完成生产构建，可以在项目根目录执行 `npm run build`；这项检查不会替代 `npm run dev`，也不会自动打开游戏。

| 命令 | 用途 |

```powershell
npx playwright install
```

## 视觉与素材

第一章采用“北镇抚司案牍 + 电影化场景”的方向：案卷、证据、呈报与封存组织工作台；人物交锋、场景进入与结案则让画面成为视觉中心。外部补充的场景图优先使用适合桌面端的横幅构图。

项目必须始终保留媒体降级能力：图片未提供、加载失败或以后被替换时，文字、选择和主线流程都不能被阻断。

## 开发约定

- 第一章是后续章节的实现样板：以查案节奏、证据反馈、权限边界和资源代价组织内容。
- 覃保坤在廖威达归入百户所后立即出现在人脉中；冯天顺只在第一章末重逢后加入。
- 夜间保全火场残料消耗 `5` 两银子，不减少健康。
- 已废弃旧的月份、风险与自由行动系统，后续功能不应恢复它们。
- 图片由外部生成或补充时，保持桌面端横幅构图，并确保缺图不会阻断流程。
