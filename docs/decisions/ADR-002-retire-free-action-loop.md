# ADR-002：废弃自由行动与突发事件循环，收束为章节主线

## 状态

Accepted

## 日期

2026-09-14

## 背景

第一章《纸灰里的银子》已经确认以查访、取证、核验、请示、保全与结案构成完整的案件节奏。旧版自由行动窗口、突发事件和对应的存档兼容逻辑没有服务当前可试玩内容，反而让后续章节占位节点暴露出并未确认的日常循环。

月份与风险系统此前已经废弃。自由行动和突发事件循环同样不再是游戏规则，必须从可执行代码、存档模型、界面与测试入口移除。

## 决策

1. 运行状态以 `chapter`、`mainlineNode`、案件临时状态、资源与已确认人物关系为核心；不保留自由行动窗口、突发事件队列或相应阶段。
2. 所有章节通过明确主线节点推进。需要停顿、核验或程序反馈时，写入具体案件节点，而不是打开通用菜单或随机事件页。
3. 当前存档版本升级为 3。版本 1 与版本 2 存档不自动迁移，也不作为当前存档读取。
4. 第一章已确认的资源代价与剧情顺序保持不变，包括夜间保全的银两 `-5` 与健康不减少。
5. 后续章节以第一章的查案节奏、证据反馈、权限边界和资源代价为样板，不新增通用自由行动系统。

## 后果

- 删除自由行动、突发事件、条件判断及其 UI、测试和存档字段。
- 第二章至第五章的占位主线直接串接，直到各章的具体案件内容经确认后替换。
- 旧存档不会被静默解释为新结构；玩家以新游戏开始当前版本。
- 历史规划文件保留用于追溯，但其中关于 7 个自由行动窗口和 5 个突发事件的内容不再具有实现效力。
