# 试玩反馈 Round 4

## 日期

2026-09-09

## 核心决定

当前开发范围锁定在第一章《纸灰里的银子》。在第一章完成可玩性完善并通过玩家验收前，暂停第二章及后续章节的开发。

第一章必须先验证并达到以下体验标准：

- 玩家能感受到实际查案，而不只是按顺序阅读和点击；
- 调查选择、证据核验和结案判断具有可理解的差异与后果；
- 覃保坤的性格通过场景、对话和办案互动体现；
- 锦衣卫身份转化为可感知的调查手段、权限边界和职业压力；
- 第一章可玩性验收通过后，才将其最终玩法、信息反馈和实现方式作为后续章节的统一标准。

## 流程影响

后续工作先进行第一章可玩性审查、方案确认、薄切片实现和玩家试玩反馈闭环。不得跳到第二章、通用章节骨架或后续章节代码。
