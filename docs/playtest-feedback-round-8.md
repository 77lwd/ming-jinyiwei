# 试玩反馈 Round 8

日期：2026-09-17

## 问题：口供整理视觉粗糙，正确选项形成固定位置套路

具体位置：第二章第一案《雨夜失押》四名证人各自完成三轮闻讯后进入口供整理，以及两组口供对照页面。

玩家反馈：原界面使用三个大号表单框承载三条陈述，标题被正文样式异常放大，整体不像案卷整理；周六及后续人物的正确答案始终是第一条选第一个、第二条选第二个、第三条选第三个，不读内容也能通过。

## 本轮修复标准

- 口供整理改为连续的案卷记录行，不再使用三个彼此分离的大表单框；
- 整理标题使用案件工作区的正常层级，不受正文大标题样式覆盖；
- 三类判断保持固定含义和固定位置，避免玩家重新学习控件；
- 通过调整陈述次序，让周六、赵七、陈老桨和阿顺的正确位置组合各不相同；
- 两组口供对照记录同样取消固定的一二三答案顺序；
- 每条记录仍须单独归类，全部完成后才可核对并誊清；
- 不改变闻讯文本、签押结果、材料形成条件和后续核验规则。
