# 第一章案件工作面 UI 设计简报

## 目标

让玩家在序章之后直接进入“正在办案”的工作面，围绕纸铺火案阅读现场、固定事实、选择调查顺序、向覃保坤请示并看到具体后果。

## 信息层级

1. 当前案情场景与现场/证物图
2. 已确认事实与当前权限边界
3. 下一步调查或请示动作
4. 按需打开的个人档案与案情记录

## 结构

- 顶部：案件名称、当前地点/阶段、音频与重新开始。
- 主区：叙事正文、现场图、事实条目、选择或继续动作。
- 档案抽屉：属性、资源、人脉、线索；默认关闭。
- 记录抽屉：已确认事实和最近后果；默认关闭。
- 第一章不展示自由行动窗口、七格进度、裸属性墙或内部节点 ID。

## 视觉与交互

- Restrained 产品配色，延续序章的深色环境与纸面内容，但不堆叠古风装饰。
- 正文保持 60–75 字符可读行长，按钮最小高度 44px，焦点环可见。
- 选择完成后先停留在具体叙事后果，再提供情境化继续动作。
- 档案/记录抽屉支持按钮关闭和 Escape，打开时不改变案件进度。

## 范围

只覆盖序章＋第一章玩家可见界面；保留既有剧情数据、状态机、图片路径和替代文本，不进入第二章或新增系统。
