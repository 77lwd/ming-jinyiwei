# 第一章案件工作面 UI Shape 简报

## 1. 功能概述

为序章后的第一章《纸灰里的银子》建立可试玩的桌面案件工作面。玩家不是浏览一篇报告，而是在覃保坤带领下阅读现场、识别具体事实、选择核验顺序、看到证据后果，并按权限完成第一宗差事。

范围覆盖第一章全部既有节点：入署、纸铺失火、三项调查、夜间保全、第二日复核、结案门槛、烧焦木牌和冯天顺重逢。保留现有剧情数据、状态机、图片路径、替代文本和既定事实边界。

## 2. 首要玩家行为

玩家在每个主线节点都能立刻回答三件事：现在人在何处、已经确认了什么、下一步可以合法做什么。核心操作是选择一项具体调查或核验，并在结果回执中理解它如何改变案件。

## 3. 设计方向

- **色彩策略**：Restrained。延续深色环境、纸面内容和朱砂行动色；不用古风装饰堆叠、紫色渐变、玻璃卡片或霓虹状态色。
- **场景句**：夜雨后的北镇抚司与城南纸铺之间，年轻校尉在冷湿的木案、残灰和灯火下整理一宗尚未定性的失银火案，覃保坤在旁边压住急躁、要求每一句话都能复核。
- **参考锚点**：电影式历史悬疑片的场景构图；档案馆/取证工作台的分层信息；桌面阅读器的稳定文字节奏。

## 4. 范围

- **完成度**：production-ready 试点。
- **广度**：序章＋第一章完整玩家可见流程。
- **交互**：真实可点击、可键盘操作、结果状态可回看；不是静态视觉稿。
- **时间意图**：先做一个完整高质量切片，再由玩家试玩反馈决定是否推广到后续章节。

## 5. 布局策略

桌面首屏采用“场景区＋办案区”同屏结构：

1. 顶部保持轻量案件栏：案件名称、当前地点/阶段、音频设置、重新开始。
2. 主内容左侧或上方为有稳定尺寸的场景图，配时间、地点和覃保坤的短批注；图片不再独占整页高度。
3. 主内容另一侧或紧邻下方为当前叙事、当前差事、已确认事实和校尉权限。
4. 调查入口以具体对象组织，例如“送样凭条”“后库起火处”“客户副联”，每项显示对象、目的、已知关联和操作结果类型。
5. 结果状态保留案件上下文：显示刚验证的事实、暂未解决的矛盾和下一步合法动作。
6. 案件记录抽屉升级为紧凑的“已核验／待核验”工作板，不显示 7 个自由窗口、内部节点 ID 或旧版窗口计数。
7. 个人档案继续按需打开；属性资源不常驻，不成为第一章的主要操作面。

## 6. 关键状态

- **默认主线节点**：场景、叙事、当前差事、事实和权限同时可见。
- **调查选择状态**：具体调查项获得选中反馈，其他选项保持可用或按剧情状态标记已完成。
- **调查结果状态**：显示证据回执、覃保坤反馈和继续核验动作，避免只剩空白文字页。
- **已核验状态**：案件工作板记录已确认事实，并保留待核验项。
- **空状态**：线索尚未形成时显示明确的“尚未形成可提交线索”，不留大片无意义空白。
- **错误/恢复状态**：图片缺失不阻断阅读；抽屉可用 Escape 关闭；刷新后状态按既有存档恢复。
- **结案状态**：清楚显示第一章独立结案、三项固定写入已完成，并提供进入后续节点的明确动作。
- **窄桌面状态**：不出现横向滚动；在较窄桌面窗口中按结构收缩，不做移动端/PWA 适配。

## 7. 交互模型

- 主线按钮推进节点；调查按钮提交一次明确的查访/勘验选择。
- 每次选择后先呈现结果回执，再由玩家点击情境化继续动作。
- 案件记录按钮打开工作板，不改变案件进度；个人档案按钮打开属性、人脉和线索抽屉。
- 抽屉支持关闭按钮、Escape 和清晰焦点环。
- 键盘 Tab 顺序遵循视觉顺序；Enter/Space 可执行当前聚焦按钮。
- 第一章不显示“跳过自由行动窗口”文案，避免把主线调查误认为旧版自由窗口。

## 8. 内容与素材要求

- 使用现有第一章 9 张外部生成 PNG；不新增内置生图，不因缺图阻断流程。
- 每个节点保留已有中文叙事和 alt 文本；可增加短标签：时间、地点、对象、证物类别、覃保坤批注。
- 不新增属性、资源、人物关系字段或剧情事实。
- 人脉页只展示姓名、关系阶段和对主角的看法；若当前数据没有看法字段，不凭空编造内容。

## 9. 实现阶段需参考

- `impeccable`：layout、typeset、interaction-design、harden、polish、audit。
- `ui-ux-pro-max`：桌面布局、可读性、暗色对比度、焦点和状态反馈。
- `frontend-ui-engineering`：React 组件实现、响应式结构、可访问交互。
- `deprecation-and-migration`：移除旧版自由窗口文案和旧展示入口。
- `browser-testing-with-devtools`：真实桌面浏览器截图、DOM、控制台和资源加载检查。

## 10. 已关闭问题

- 不进入第二章或 Task 5。
- 不改剧情设计和状态机边界。
- 不做移动端适配、PWA、商店、素材生成或月份/风险系统。
- 不把属性资源重新放回常驻主界面。
