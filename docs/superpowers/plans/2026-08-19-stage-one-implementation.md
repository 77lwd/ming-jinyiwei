# 《我在明朝当锦衣卫》阶段一开发计划

## 目标

将现有“序章至第3月”MVP扩展为阶段一“立足”（第4至24月）。阶段一以第12月“祥云商行案”、第18月“第一次碰壁”、第24月“意外突破”为固定主线节点；月度日常、突发事件和风险后果围绕这些节点变化，但不得遮蔽主线。

## 已确认边界

- 保留现有序章、第1至3月、存档、PWA、风险、健康、月度结算和五类行动。
- 第4至24月沿用每月3点行动力与本地自动存档。
- 阶段一完成后显示“阶段一完成”，不提前实现第25月及以后内容。
- 不增加账号、联网、云存档、付费、广告或与主线无关的大型战斗系统。
- 重要剧情不能使用占位文本；每个主线节点必须有完整叙事、至少3条有代价的选择和可验证效果。

## 架构决定

- 月份改为受引擎边界保护的数值，而不是 `1 | 2 | 3` 联合类型；本阶段的上限为24，为后续扩展至120月保留同一接口。
- “是否结束游戏”不再由月份硬编码；由阶段配置的终点决定。第3月结算将继续进入第4月。
- 月度主线使用数据驱动的调度表，按“风险反噬 -> 月度突发 -> 固定主线 -> 月度结算”优先级触发；每个节点只能完成一次。
- 随机事件采用确定性、可复现的候选池轮换，而不是不可测试的真随机；事件候选由月份、风险、健康、关系和线索条件过滤。
- 旧版第3月完成存档需要读取为可继续的第4月月初状态，不能让现有玩家丢档。

## 阶段一月度节奏

| 月份 | 主线节奏 | 目标 |
| --- | --- | --- |
| 4-5月 | 第一条线的余波 | 建立调查计划，开放烧焦木牌的后续追查和更有代价的日常事件。 |
| 6-11月 | 西市与商路的反复取证 | 让玩家通过日常、关系和资源积累，为商行案准备不同调查条件。 |
| 12月 | 节点2：祥云商行案 | 获得景王、三十万两、十五年前和沈敬亭私账朱记之间的第一组关联。 |
| 13-17月 | 商行案后的跟进与反侦察 | 根据节点2选择，改变保护、隐蔽调查与商行接触的路径。 |
| 18月 | 节点3：第一次碰壁 | 孙玉堂明确施压，玩家决定停查、示强、求助或反侦察。 |
| 19-23月 | 压力下的补证 | 风险、关系和健康的代价更明显，准备账册残页的可靠性。 |
| 24月 | 节点4：意外突破 | 取得能连接商税、商行、孙玉堂、景王府和东厂的确凿证据，进入第二阶段的门槛。 |

## 任务列表

### 阶段 A：可扩展月份与兼容存档

#### 任务 1：将月份推进扩展到第24月

**内容：** 用阶段配置替代“第3月即结束”的硬编码，保留纯引擎的月份边界检查。

**验收：**
- [x] 第3月结算后进入第4月月初，不再进入完成页。
- [x] 第24月结算后进入阶段一完成页。
- [x] 不能推进至第25月。

**验证：** 引擎单测覆盖第3、4、24、25月边界；完整构建通过。

#### 任务 2：迁移既有 MVP 存档

**内容：** 将旧“第一章完成”存档安全映射到第4月月初；保留已经获得的属性、健康、财富、关系、线索和旗标。

**验收：**
- [x] 旧存档可继续，不白屏也不重置。
- [x] 损坏存档仍走现有安全回退。

**验证：** 保存仓库单测覆盖迁移与错误数据。

### 检查点 A

- [ ] 从新游戏可连续进入第4月。
- [ ] 旧版完成存档可继续。
- [ ] 单测、类型检查、Lint、构建通过。

### 阶段 B：数据驱动的主线和月度调度

#### 任务 3：建立阶段一月度调度表

**内容：** 将固定主线、月度突发和风险反噬纳入同一调度入口，并保持既有“主线不能漏、事件不能重复”的规则。

**验收：**
- [x] 第12、18、24月固定主线各出现一次。
- [x] 高风险反噬仍优先于普通月度事件，处理后可继续当月主线。
- [x] 主线完成前不能越过当月结算。

**验证：** 引擎单测覆盖事件优先级、去重和月份顺序。

#### 任务 4：扩展条件化日常与月度突发池

**内容：** 为阶段一前、中、后期分别准备事件候选；调度按月份、风险、健康、关系和线索过滤，仍保留可预测的轮换顺序。

**验收：**
- [x] 同一行动不会反复播放同一事件。
- [x] 已知线索、低健康或高风险会改变至少一类可遇事件或选择条件。
- [x] 普通训练和无关社交不会增加旧案调查风险。

**验证：** 数据与引擎单测覆盖过滤条件和结果差异。

### 检查点 B

- [ ] 可从第4月运行至第11月，主线不会提前或丢失。
- [ ] 高风险月末、月度突发和主线可按正确顺序连续处理。
- [ ] 桌面和手机试玩流程无横向溢出。

### 阶段 C：三条固定主线的完整切片

#### 任务 5：实现第12月“祥云商行案”

**内容：** 实现商行账房死亡案、商行调查路径和四项结案选择；建立景王、三十万两、私账朱记的线索集合。

**验收：**
- [x] 四条选择具有不同的线索、关系、风险或旗标结果。
- [x] 后续事件可读取“独立调查、周寒川保护、魏承恩没收、沈敬亭低估”等结果。
- [ ] 节点有专属配图和语义替代文本（等待资源）。

**验证：** 引擎、组件、浏览器流程分别覆盖至少一条公开路径和一条隐蔽路径。

#### 任务 6：实现第18月“第一次碰壁”

**内容：** 实现孙玉堂施压、断刀威胁和四条应对路径，兑现第12月选择带来的保护或孤立差异。

**验收：**
- [x] 停查、示强、求助、反侦察都有明确即时代价与后续旗标。
- [x] 示强路径受到武力门槛限制；求助路径改变周寒川关系。
- [x] 事件能明确说明风险为何升降。

**验证：** 条件锁定、四条结果和后续可读取旗标均有单测。

#### 任务 7：实现第24月“意外突破”

**内容：** 实现账页来源、档案核对和四项证据处置选择，生成阶段二所需的确凿证据链。

**验收：**
- [x] 账页、商税贪腐、沈敬亭、孙玉堂、景王府、东厂均以结构化线索或旗标记录。
- [x] 第24月完成后进入“阶段一完成”，并展示真实阶段收获。
- [x] 第25月尚不可进入。

**验证：** 全程浏览器测试从第1月走至第24月；至少两条不同证据路线可达。

### 检查点 C

- [ ] 三个阶段一节点均只出现一次并能影响后续。
- [ ] 完整第1至24月流程可存档、刷新、继续。
- [ ] 单测、类型检查、Lint、构建、桌面与移动端浏览器测试通过。

### 阶段 D：表现与发布更新

#### 任务 8：补齐阶段一关键视觉与声音

**内容：** 为三个主线节点和必要结果页接入对应图片；在保留当前全局音乐和音效设置的前提下，添加可降级的场景音频策略。

**验收：**
- [ ] 关键节点的图片表现当前人物、地点或证物，不使用通用古风背景。
- [ ] 所有新增静态资源进入 PWA 离线缓存。
- [ ] 图片、文字和控制在320px与桌面均不遮挡。

**验证：** 浏览器截图、离线重载和可访问性检查。

#### 任务 9：阶段一发布验收与 Netlify 更新

**内容：** 完成质量门禁，构建新 `dist` 并更新现有 Netlify Drop。

**验收：**
- [ ] 完整测试、类型检查、Lint、构建和浏览器测试均通过。
- [ ] 手机可打开公网地址、继续本地存档并添加到主屏幕。

**验证：** 发布后在真实公网地址复查首页、序章、存档和第4月入口。

## 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 直接把月份改为无限 number | 可能越界进入未实现内容 | 阶段配置在引擎中显式限制为24。 |
| 旧完成页存档无法继续 | 已试玩玩家丢进度 | 先写迁移测试，再实现兼容映射。 |
| 21个月内容变成重复刷任务 | 阶段一节奏失去张力 | 先完成月度节奏表和条件化事件池，再逐月填充内容。 |
| 随机事件遮蔽主线 | 玩家错过剧情或困惑 | 使用显式事件优先级和每月次数上限。 |
| 新图和音频导致移动加载变慢 | 首屏和离线体验变差 | 压缩资源、只为关键节点加载，并用PWA缓存验证。 |

## 实施顺序

先执行任务1与任务2，完成检查点A后，做任务3与任务4。随后按任务5、6、7逐个交付主线节点，每个节点完成后给你一轮可试玩版本；任务8与任务9作为阶段一完整发布前的收尾。
