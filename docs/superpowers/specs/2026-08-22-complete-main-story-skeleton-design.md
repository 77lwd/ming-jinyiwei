# 完整主线骨架设计：一张看不见的网

日期：2026-08-22  
状态：阶段骨架与旧版人物审查结论已获玩家确认  
范围：完整主线的叙事结构、信息揭露节奏、已确认角色在主线中的边界。本文件不确定第二章及以后具体案件、案件配角、数值系统或代码实现。

## 1. 目标

主线要让玩家经历从局部、普通且可独立解释的事件，逐步看见一张长期、稳定且层层受保护的权力网络。它不依赖不断升级的名词、早期点名景王、反派自白或一条直线任务提示推进。

玩家的最终目标是查清廖家灭门案的全部真相。最终揭露应同时兑现：廖威达的个人经历、多个案件的事实链、锦衣卫内部的权力关系，以及景王之网如何运转。

## 2. 已确认主线核心

- 景王保留为整张网最终绕不过去的权力顶峰。
- 这张网的可怕之处首先是运转流畅，而不是某一种单独犯罪、某个显眼阴谋或景王亲自向每一层下令。
- 普通人只能看见一桩火案、一笔生意、一次赈济、一份公文或一场结案。多数参与者只知道自己的职责或利益，不知道整张网，也不知道景王是最后主人。
- 网络长期替景王及同类权力者谋利、遮掩和排除障碍。它通过不同人分别完成不同的一步，而不是靠单一首脑现场操纵一切。
- 前期碎案必须各自成立，不能在玩家刚接触时就显眼地指向同一网络、廖家旧案或景王。
- 后续只能通过人物、时间、物件、资金、命令与处理程序的交叉验证，把碎片串联为同一张网。
- 每次玩家以为已经得到解释，后续事实都应证明该解释只成立一部分；推进必须包含收获、误判、损失、期限、立场变化或对既有证据的新解释之一。
- 最终景王必须由多层事实相互咬合逼出，不得依赖早期直白提示、反派自白或一封直接署名的密信。
- 廖家灭门是这张网清除试图看清它的人的结果。当前案件不得反复被写成十五年前旧案的直白映照。

主线体验目标为：

```text
一个人的恶意
-> 一群人熟练的操作
-> 多个行业与程序彼此配合
-> 有权力保护这套机制
-> 最后才看见景王
```

## 3. 已确认不变基线

- 主角廖威达十八岁，是北镇抚司校尉，具有一线查访、缉捕和执行资格，没有独立调人、越级查档或决定大案走向的权力。
- 廖家于十五年前被灭。李慕尘参与灭门后又救走幼年廖威达，将其留在村口；独居老人只负责收养，不参与旧案。
- 烧焦木牌在十五年前的廖宅大火中烧过，之后被人为刨去身份并混入旧料。首章玩家只能确认旧火痕、火后刨削痕、钉孔和漆边，不能确认其来自廖宅。
- 《纸灰里的银子》为首章第一案的只读基线。木牌与该案犯罪无直接关系。
- 覃保坤、周寒川与冯天顺的已确认人物设定、关系和信息边界不因主线骨架而改写。

## 4. 全篇阶段骨架

### 序章：火中幸存

序章采用“有限全景 + 幼年主观”的镜头。全景可呈现廖宅被围、不同位置起火、家仆逃散、有人拦住出路与蒙面人入宅，使玩家明确这是一场有组织的灭门；镜头不得给出执行者真实面目、姓名、归属、命令内容或可追踪线索。随后切入三岁廖威达的主观片段：火光、门内外混乱、被人带离和被留在村口。他无法识别凶手、理解灭门原因、记住阴谋信息或认出李慕尘。

**玩家知道：** 廖家被灭，自己幸存。  
**玩家不知道：** 谁下令、谁参与、父亲查到什么、救人者是谁。  
**作用：** 建立个人伤口，不提供可直接追踪的主线答案。

### 第一阶段：新案里的旧物

十五年后，廖威达进入北镇抚司，完成《纸灰里的银子》。纸铺案独立闭合；火场露出一块被烧过、又被刻意刨去字迹的木牌。

**玩家知道：** 木牌曾有标识用途，经历旧火后被人刻意抹去身份，不该作为废料丢弃。  
**玩家不知道：** 它原本标识什么、谁抹去字迹、如何流转到纸铺、是否与廖家有关。  
**作用：** 让过去作为一个具体但暂时无从解释的异常物进入现在，而非成为可重复点击的任务按钮。

### 第二阶段：各自成立的碎案

廖威达处理若干性质、人物和表象不同的案件。每一案都有独立的受害者、局部冲突、调查过程与结案结果，不作为“递主线线索”的换皮任务。

这些案件可分别呈现：有人在程序中被挤走、一件东西在手续中易主、一件事在案卷中被写成另一个结论。它们只是在各自关键的交接处留下轻微异常。

**玩家知道：** 某些人和程序在关键时刻做出不合常理却暂时可被局部解释的处理。  
**玩家不知道：** 这些案件是否有关，异常由谁造成，木牌是否属于其中任何一条线。  
**作用：** 先让玩家相信碎案就是碎案，避免早期将任何异常自动理解为景王阴谋。

### 第三阶段：第一次串线

玩家通过不同案件的交叉事实，发现它们不是同一批人犯下，却都在最关键的交接处被导向同一类结果：应继续查的事项被截断、应留下的人被带走、应归档的材料换了去处。

**玩家知道：** 存在能跨过不同案件和层级、影响调案、调人、封卷及后续处置的人。  
**玩家不知道：** 此人是否是整张网主人，网络具体为谁服务，廖家灭门是否与之有关。  
**作用：** 推翻“各自偶然”解释，但不直接给出最终答案。

### 第四阶段：看见节点

交叉事实最终汇合到一名锦衣卫内部高层。他掌握影响案件流向、人员调度、卷宗归档和后续处置的一层权力。廖威达作为校尉与其最多有一两次有分量的直接交集；其余存在感由批示、权限后果、旁人反应和制度痕迹呈现。

玩家、覃保坤和周寒川以各自职权推动行动。该高层确实参与过廖家灭门后的封锁、清理和改案，也确实主动维护一套跨部门的长期利益机制；但第三章和第四章正文只需要证明其为真实有罪的高节点，不在此阶段直接确认他是否知道景王本人。

**玩家知道：** 抓住此人有理由被理解为抵达阶段性终点；此前多数异常都能在其掌管层级找到落点。  
**玩家不知道：** 他是否就是整张网主人。  
**作用：** 构成真实小高潮。此人不是替罪羊，玩家没有抓错。

### 第五阶段：胜利后的坍塌

该高层落网后绝不供出景王。景王实际控制其家人；家人不承担独立主线功能、不必出场或展开支线，但该控制在高层被捕后仍有效。

高层落网后，他所负责的货、人、卷宗和利益链并未停下，而是在既定的合法程序中由别处接走。玩家由案件链和接管痕迹确认景王确实位于其上，但此时没有足以将案件推至景王的完整证据。

**玩家知道：** 高层是这张长期利益网络的一层高节点，主动维护并从中获益；网络可替换该节点继续运转。  
**玩家不知道：** 高层是否知道景王本人，如何证明景王对整张网的最终控制，以及旧案中各层参与者如何咬合。  
**作用：** 推翻“抓住大人物即抓住整张网”的解释。玩家不是失败在没有能力，而是第一次看见网络本身比一个人更大。

### 第六阶段：旧火与现在合拢

玩家从高层倒台后的接管痕迹反向追查网络为什么能稳定运转。木牌则通过可信的旧物清册、尺寸、漆色、钉孔和刮痕等实物比对，确认来自廖宅火场。

廖承志当年的调查不再被理解为偶然得罪某个人：他碰到的是这套机制的一部分，因此廖家被多个层级共同处理。每个人各做一步，最终共同造成灭门。

**玩家知道：** 廖家不是单一仇杀或某名执行者的私人罪行；十五年前与现在的碎案属于同一长期机制。  
**玩家不知道：** 尚缺哪些能公开互证的事实，才足以把整张网的责任推到景王。  
**作用：** 让个人复仇、当前案件和网络真相真正汇合。

### 终局：主人现形

玩家不依赖高层口供，而是将当前案件的不同事实链、火后旧物、人员调度、卷宗处理、利益去向和旧案记录互相印证。李慕尘参与灭门又救走廖威达的事实，必须在这条证据链中得到解释，但不得单独承担证明景王的功能。

景王成为唯一能够解释长期受益、层层保护、多人协作与多次清理的人。最终冲击来自玩家重新理解此前普通事件始终在为同一个权力中心运转，而非来自突然公布一个名字。

## 5. 角色边界

### 廖威达（基础人物设定已确认）

廖威达十八岁，北镇抚司校尉。三岁时经历廖家灭门，被李慕尘救走后留在村口，由独居老人养大。他幼年已通过日常生活知道父亲是锦衣卫，长大后因此想进入锦衣卫；他不记得父亲如何办案，不知道父亲调查过什么，也不知道灭门真相。

其外在默认气质为沉默寡言、心思缜密、冷静、情绪稳定。他不爱以言语表达关心，更多在无须玩家选择的日常场景中默默把事做在前面。上司否定其判断时，他不会失态或赌气；会接受当下处置，并在事后复核自己的推断。

廖威达是玩家行动与推理的中心。上述内容只约束前史与无选择场景的呈现；案件判断、关系处理、追问旧案、冒险、妥协与价值取舍均由玩家决定。他不能因主角身份随意接触高层或越级推动行动。

- 覃保坤以直属百户身份承担日常办差、看人和程序压力，不替玩家自动串联主线。
- 周寒川知道廖威达身世，且与旧案存在历史关联；他不得在前期直接解释真相。其习惯独自承担的缺口，可以在网络压力下造成真实代价，但不能制造无依据隐瞒。
- 冯天顺是威达的兄弟，不是可反复刷取的情报、好感或武力资源；他只在其正常生活、军中身份或具体案件自然需要时进入。
- 李慕尘的身份、参与灭门和救走幼年威达为已知作者层事实；成年后的进入方式与其掌握的信息必须在具体案件设计时独立建立因果。

### 李慕尘（关键人物，基础范围已确认）

李慕尘是景王之网执行势力中的剑客。十五年前，他受命参与廖家灭门；行动中见到三岁的廖威达，因一时恻隐违令救走孩子，并让其余执行者相信孩子已死于火中。他之后仍留在原势力，继续办事并逐步上升，既不长期愧疚，也不暗中保护或寻找廖威达。

成年后的廖威达与李慕尘此前互不相识。威达只能在追查一桩大案时顺着事实链查到李慕尘；初见时李慕尘也不知道他就是当年放走的孩子。身份揭露必须由案件中的可信事实与互动促成，不能靠巧遇、旧物一眼相认或旁白揭示。

李慕尘是关键人物而非常驻伙伴。他不承担长期陪伴、日常互动、传授能力或额外支线；后续只在其被大案查出、身份揭露和旧案证据链真正需要时补充场景与具体行为。

## 6. 明确禁止

- 不把主线写成每章稳定获得一层“大人物线索”的直线升级。
- 不让每个案件都成为冤案、灭口案、账目案或十五年前旧案的直接映照。
- 不在早期直接写出景王、王府、完整商税网络、东厂阴谋或旧案答案。
- 不让中段高层变成不知景王、被蒙骗的小头目、与景王竞争的独立主人，或被主角频繁接触的私人导师。
- 不让高层以口供、忏悔或临终自白替玩家完成景王真相。
- 不把高层家人扩展成独立角色线、苦情支线或新的阴谋来源。
- 不以重复日常、无后果资源、模板月度事件或纯数值成长填充主线间隔。

## 7. 骨架级逻辑自检

- 高层可成为阶段性终点，因为此前多个独立案件的关键交接实际都能回溯到其权限层；他不是凭作者声明突然被定为大反派。
- 高层确实有罪、确实参与旧案，并在幕后设定上知道景王；但玩家在第三、第四章只需确认其为真实有罪的高节点，不提前获得“他知道景王本人”的明确信息。抓到他仍是玩家的真实胜利；网络继续运转说明其不是主人，而非说明此前证据错误。
- 高层沉默的原因明确为景王控制其家人，且在被捕后仍具现实效力；不依赖含糊恐吓或额外复杂把柄。
- 玩家确认景王在高层之上，来自案件链和高层倒台后的接管痕迹；不能将这种确认误写为已具备公开定罪景王的证据。
- 木牌在首章只构成异常，在第六阶段才经实物与清册比对确认来源；不依赖三岁记忆或未经核实的官方编号。
- 廖家灭门的共犯结构与网络核心一致：多人只做一小步，最终共同完成清除；它不要求每一桩当前案件都直接复刻灭门过程。

## 8. 后续设计顺序

1. 完成廖威达、李慕尘、景王、魏承恩和廖承志的主线相关人物设计；覃保坤、周寒川和冯天顺不重做，只在具体剧情中检验已定人物基线。
2. 基于人物设计，确定第二、第三和第六阶段的具体案件组合，并完成案件因果、信息边界、角色进入方式与骨架级逻辑自检。
3. 将已定稿案件嵌入完整第一章设计，审阅后才写实施计划。
4. 玩家确认实施计划后，才开始代码修改。

## 9. 旧版人物审查结论

以下结论只决定人物是否进入新主线的设计池，不继承旧版的剧情、职能、关系数值或命运。

- 魏承恩：保留姓名并重做，承担中段阶段性假高潮中的锦衣卫内部高层位置；不得沿用旧版早期直接施压、终局反派或无条件掌控全局的写法。
- 沈敬亭：保留姓名并重做，作为网络中商人一层的候选人物；不得沿用“洗钱总管”“早期直接提供主线答案”的写法。
- 孙玉堂：保留为景王府执行层候选人物；不得沿用主角早期直接仇人、早期暴露景王的写法。
- 杜文昭：保留为档案或旧案处理层候选人物；不得重做为另一名全知大反派或替代魏承恩、景王的主线功能。
- 方正言：保留为后期证据进入公开程序时的候选人物；不得自动相信主角或成为政治资源外挂。
- 郑九、柳如烟、崔公公、天刀门门主不作为新主线核心人物保留。东厂、商人或灭门执行层是否在具体案件中出现，须按新主线骨架重新设计，不能从旧版人物设定直接继承。
- 崇祯皇帝只作为时代权力背景，当前不设为独立剧情人物。
