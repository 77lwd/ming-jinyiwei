# 声望与人脉整理审阅稿

状态：已确认；不进入代码

## 一、声望

声望代表“别人公开如何评价廖威达办差”，影响的是公开场合的信任和办事阻力，不是官职或政治权力。

声望变化必须来自可追溯行为：按程序结案、保护证人、公开承担责任、保住证物、违规越权、把责任推给无辜者或公开办差失误。普通训练、喝酒和私下闲聊不改变声望。

### 四个阶段

**低声望：**

- 普通人和基层书吏只愿按最低限度程序接待；
- 调档、取证和证人安置需要更多书面手续或额外等待；
- 上峰会要求更完整的证据说明；
- 仍可办案，但更依赖覃保坤的正式背书、第三方见证或银两支付合法成本。

**普通声望：**

- 常规公务能获得正常配合；
- 证人更愿意留下可核验的时间、地点和经手事实；
- 上峰会认真阅读有证据的建议，但不会自动批准越权请求；
- 公开冲突中，双方更可能先按程序说话，而不是立即把廖威达当成无理闹事者。

**较高声望：**

- 基层人员可能主动提醒明显的记录异常；
- 证人更愿意留下姓名、时辰和书面陈述；
- 合理协查申请更容易获得差役或见证人配合；
- 地方衙门更愿意先保全材料，再讨论归属；
- 公开冲突中，不容易被直接视为无理闹事者。

**高声望：**

- 正式报告更快进入复核流程；
- 其他机关更愿意按文书配合，减少反复推诿；
- 证人安置、证物保管和临时协查更容易得到优先处理；
- 廖威达公开承担责任时，上峰更愿意给一次合规补救机会；
- 部分需要公开身份可信的调查方式才会开放；
- 高声望不能让高官服从、不能调兵、不能查封、不能替代证据，也不能让敌对人物改变立场。

声望的差异必须体现在“别人是否主动配合、手续需要多久、公开质疑有多大”，而不是只显示一个数字。

### 声望变化的具体来源

声望只来自公开可被记录或传播的办差结果：

- 按程序结案，并明确区分责任；
- 保护证人，且没有把责任推给无辜者；
- 在公开场合保住关键证物；
- 替同僚或下属承担合理的程序责任；
- 在危险情况下完成职责，但没有滥用武力；
- 获得地方衙门或上峰对办差记录的正式认可。

会降低声望的行为：

- 证物丢失或保管混乱；
- 为了结案把责任推给无辜者；
- 当众越权抓人、逼供或毁坏现场；
- 接受来路不明的好处；
- 办差失败后隐瞒事实；
- 让同僚替自己承担本应由自己负责的错误。

隐藏调查不会自动增加声望，训练、喝酒和赚钱也不会自动增加声望。

### 同一场景的四阶段差异：调取火灾善后副簿

- 低声望：对方要求补交两份文书，需要等待半天；没有银两或关系时可能错过当天核验时间；
- 普通声望：出示委派文书后正常调阅，但只能看到基础登记，需要继续申请副本；
- 较高声望：府衙书吏主动提醒还有一份旧副簿，少走一次手续，但不会替主角判断木匣归属；
- 高声望：核验申请优先处理，当日即可取得见证和封存协助，但仍不能查阅无授权密档。

## 二、人脉

人脉不是总好感度，而是具体人物关系卡。只有主角已经认识并发生过有效互动的人，才会进入人脉列表。

每张关系卡至少显示：

- 关系身份；
- 当前态度；
- 已形成的共同经历或欠情；
- 能请求的一项具体帮助；
- 明确不能请求的事项；
- 帮助次数或当前人情代价；
- 帮助可能给对方带来的风险。

界面示例：

### 冯天顺

- 关系：儿时兄弟；
- 当前态度：担心廖威达，但尊重他不愿谈的过去；
- 可以请求：送药、递信、提供自己辖区的正常军中记录；最终章可带自己直属京营弟兄支援；
- 不能请求：透露景王身份、调动其他营队、替主角查案；
- 已形成经历：共同长大、互相帮过忙；
- 代价：他提供军中便利时，可能承担军中问责；支援行动只在符合权限和剧情的时机发生。

### 覃保坤

- 关系：百户与校尉的上司关系；
- 当前态度：认可办案能力，要求廖威达守规矩；
- 可以请求：批准协查、封存、调差役、承担程序责任；
- 不能请求：替主角直接推理、无文书拘押高层、把所有责任替主角承担；
- 已形成经历：在多桩案件中共同办差；
- 代价：每次扩大协查范围都需要充分理由，批准后覃保坤本人承担程序压力。

### 周寒川

- 关系：父亲旧友、有限保护者；
- 当前态度：关心廖威达，但刻意保持克制；
- 可以请求：核对有限旧式记法、确认交接程序、完成活体认证；
- 不能请求：直接说出父亲调查全貌、提前揭露景王、替主角完成推理；
- 已形成经历：与廖承志的旧交、对廖威达的照看；
- 代价：越接近旧案，他越可能被迫承担程序和公开举证风险。

## 三、人脉的实际变化

关系不会因为每月经过自动上涨，也不会因为重复喝酒稳定增加。

关系变化来自具体行为：

- 兑现承诺：信任增加，可请求一次具体帮助；
- 共同承担风险：关系更深，但对方可能留下问责或伤势；
- 尊重边界：即使没有数值上涨，也会保留长期稳定的帮助条件；
- 越过边界：对方拒绝某类请求，或只提供最低限度帮助；
- 让对方失望：关系进入暂时冷却，必须通过新的行动修复；
- 让对方替主角承担过重代价：关系不会简单上涨，可能出现感激和不满并存。

## 四、声望与人脉的区别

| 项目 | 声望 | 人脉 |
|---|---|---|
| 对象 | 一群人、同僚、百姓、上峰 | 某个具体人物 |
| 来源 | 可公开看见的办差结果 | 共同经历、承诺、欠情和边界 |
| 作用 | 公开配合、手续阻力、报告可信度 | 在特定时机提供特定帮助 |
| 限制 | 不能替代权限和证据 | 不能违背人物目标和能力 |
| 失败 | 公开评价下降，办事更慢 | 某个人拒绝、冷却或要求补偿 |
| 恢复 | 靠新的公开办差记录 | 靠兑现承诺、修复关系或共同经历 |

例子：

- 廖威达声望高，陌生库吏可能更愿意按规矩接待他，但这不等于冯天顺会提供额外帮助；
- 廖威达与冯天顺关系深，即使声望不高，冯天顺仍可能送药，但不会替他调动别人的军队；
- 覃保坤信任廖威达，不代表他会批准没有文书依据的请求；
- 周寒川关心廖威达，不代表他会泄露廖承志没有留下的答案。

## 五、反刷规则

- 重复喝酒不增加口才、人脉或情报；
- 重复送礼不直接提升关系，且可能造成边界问题或声望下降；
- 同一人物的同一帮助在同一阶段只能使用一次，除非剧情条件发生实质变化；
- 关系帮助必须消耗时间、机会、人情或让对方承担明确风险；
- 未认识的人不显示在左侧人脉列表；
- 关系达到高阶段仍可能拒绝违背底线的请求；
- 声望高低不改变主线真相，只改变公开配合和程序阻力；
- 人脉不能直接生成证据，只能提供一条有来源、有边界的取得路径。

## 七、关系阶段影响（当前基线）

本节为用户基本通过的阶段影响方向，后续仍需结合具体人物事件校正：

- 决裂：不再视为自己人，私人交谈关闭，失去该关系能提供的帮助；
- 敌对：主动阻碍、隐瞒或站到对立面，需要证据、文书或其他人物介入；
- 反感：不愿多说，正常公务仍可办理，私人请求通常被拒绝；
- 疏远：刻意保持距离，不主动联系或提供额外信息，需要先修复关系；
- 陌生：只进行正常公务或礼节性对话，不主动关心或额外帮助；
- 熟悉：愿意交流普通情况，对话自然，但不承担明显代价；
- 信任：相信主角办事可靠，在普通风险下愿意有限配合或作证；
- 亲近：主动关心主角，在重要时刻愿意承担部分风险，但不违背身份和原则；
- 深厚：关系经受重大事件考验，可在关键剧情中主动保护或承担严重代价，但不违背人物核心性格。

阶段影响原则：负面阶段会造成阻碍，中性阶段不提供额外关系便利，正面阶段逐步增加配合和支持；关系不会自动生成道具、情报或主线答案，也不会单独堵死主线。

## 九、用户确认记录

用户已确认本模块的核心价值：人脉帮助必须嵌入具体剧情场景，体现为符合人物身份的可行处理路径，而不是页面上的奖励清单或可重复领取的功能。关系越好，越可能获得有限协助；协助不能直接给出主线答案、越级授予权限、替代证据或单独堵死主线。

用户已确认人脉页面的最终显示格式：每张关系卡只显示人物姓名、关系阶段、他对你的看法；不增加帮助清单、次数、人情值或其他额外字段。

人物对主角的看法只根据其亲眼看见、亲自经历，或后来从可靠记录中确认的事情改变。变化来源限定为五类：

- **对待方式：** 是否在对方受伤、被误解或需要保密时提供实际帮助，是否把对方当工具；
- **办事方式：** 是否守规矩、是否在证据不足时继续核验、是否越权、是否把责任推给他人；
- **承诺兑现：** 是否按时送信、保护证人、保守约定的秘密或完成答应的事情；
- **代价承担：** 是否让对方承担问责、伤势或暴露，是否在合理范围内主动承担自己的责任；
- **关键选择：** 在保护证人、保全证物、公开名声、朋友安全和调查推进发生冲突时，主角最终选择了什么。

普通小事不频繁改变关系。一次行为先改变“他对你的看法”文字，多次同方向的看法变化才推动关系阶段升降。关系不会因为一句话从陌生跳到深厚，也不会因为一次小失误立刻决裂。

示例：覃保坤原本认为主角“有判断力”，主角多次越权后，看法变为“有判断力，但不懂得收手”；主角后来承认错误并承担责任，可能恢复部分信任，但不会立即回到原阶段。冯天顺即使仍然信任主角，也可能因为多次被拖入问责而变为“认可你，但开始担心你会把身边人也拖进去”。
