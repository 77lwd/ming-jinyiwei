# 第二章详细设计：失号凭照（修订版）

日期：2026-08-26
状态：已确认，已完成三案逐案自检与整体串线复核
范围：第二章三桩固定顺序案件、案件间承接、章末总簿核验。不涉及代码、具体数值和制度史最终定名。

## 1. 固定顺序与章节节奏

第二章只按以下顺序承办正式差事：

```text
《雨夜失押》
-> 结案、移交、短暂休整
-> 《空屋里的嫁妆》
-> 结案、移交、短暂休整
-> 《倒在更鼓前的人》
-> 三案材料归档
-> 《失号凭照》总簿核验
```

廖威达不会同时查两桩案子。每桩案子都在前一桩阶段性结案、证物移交和覃保坤确认下一张差牌后才开始。

每桩正式差事占用 4 至 6 日的案件窗口；窗口内不插入训练、喝酒、赚钱或随机日常。第一案和第二案结案后各固定开放一个自由行动窗口，用于休养、抄录材料、处理一项人物/文书事务、案件准备或有目的的训练；玩家也可跳过。窗口不会因结案速度、健康、银两、属性或关系被取消。上一案至少有一项状态会传入下一案：特定证人是否愿意配合、公开办差声望、可用银两、健康状态或已盖印的材料副本。

三案各自成立，玩家直到章末总簿核验才确认三张凭照经过同一内部转收房。第二章不出现魏承恩、孙玉堂、杜文昭、景王、廖家旧案或木牌来源。

## 2. 共同凭照规则（局部可见，不提前串线）

本章暂用“临时凭照”作为架空工作名，分为押送、封验、夜行三种纸种。每张凭照有编号、纸种、蜡记、用途栏、副联和应回收状态。正式历史名称、签发层级和纸面栏位在实施前统一核验。

三案中凭照外流的共同最小机制如下，但玩家在单案中只能看到局部：

1. 百户所文书流程把一张凭照登记为“错印/待回收”，按规矩应剪角并封存；
2. 凭照原纸被送到内部转收房，交接条只记职号、纸种和蜡记，不记实际领取人的姓名；
3. 领取人以合法差役或受托文书的身份取走原纸，绕过了“核对本人、核对用途、回收原纸”中的一项；
4. 凭照被拿到外部使用，使用后没有按原流程回到百户所，而是被收走、藏起或随案物移交；
5. 单案只能证明自己的外流链，只有章末将三案材料与本所总簿对照，才能发现同一转收房这一共同节点。

这套机制说明“程序被利用”，不说明谁控制转收房，更不直接指向任何高层。

## 3. 第一案：《雨夜失押》

### 3.1 差事入口

货栈斗殴致死案中的马骁是封箱交接的关键在场者。地方衙门尚未对封箱问题作结，覃保坤收到书面差牌，要求将马骁转送指定看押处，询问一批账货不符的封箱。

暴雨夜，押送车辆在桥头翻倒。押役声称马骁趁乱挣脱逃走，锁具、翻车和夜路混乱都能暂时支持这一说法。覃保坤命廖威达复核失押责任和凭照使用情况。

### 3.2 局部外流链

- 当日下午，百户所文书把一张押送凭照登记为“错印待回收”，原纸没有剪角；
- 文书房按惯例把原纸送往内部转收房，交接条只写职号和押送纸种；
- 一名自称负责回收废凭的文书凭同职号取走原纸，真正的姓名没有被登记；
- 他把凭照交给负责接应马骁的人。凭照上的编号和蜡记真实，但“领取人”和“最终交接地点”栏为空；
- 押役只核对了编号和蜡记，没有按差牌回拨本所核验本人和用途，因对方以违令相胁而放行；
- 马骁被带走后，凭照没有回到百户所，交接存根被一名押役藏起。

玩家在本案能查到“真实凭照被违规使用”和“押役绕过回拨核验”，不能查到内部转收房的上层控制者。

### 3.3 可验证事实

- 锁扣没有从内侧挣脱的磨损，车辕折痕也不符合押役描述的翻车方向；
- 渡头船夫看见一辆有押役同行的篷车离开，车上有被绑住双手的人；
- 雨披夹层里的交接存根写有马骁姓名、时辰、凭照编号和模糊领取别号；
- 凭照编号和蜡记真实，但用途栏没有具体领取人和终点；
- 押役的原始口供与事后统一口径不一致。

这些证据证明马骁不是自行逃跑，押役隐瞒了真实交接；不证明谁下达了转移命令。

### 3.4 玩家处理与不可逆后果

**先固定押役口供**：覃保坤批准分开看押和询问。玩家保住原始口供与交接存根，能更稳地固定押役责任；但篷车已离开，河埠路线变冷。传入第二案的状态是“责任材料完整，外部去向不明”。

**暂不公开存根，让押役带路**：覃保坤批准有限跟查，玩家顺着押役找到河埠和中转脚夫，取得领取人的假称与凭照编号；押役随后统一口径，失押责任难以公开坐实。传入第二案的状态是“外部交接链完整，但押役证词不稳定”。

### 3.5 资源与养成作用

- 武力：可以在摇晃车架下先固定锁具和存根，承担健康代价；也可等覃保坤批准差役清障，少掉半日调查时间。
- 智谋：更早发现车辙、锁具和口供矛盾，安排先查现场还是先查交接；不直接显示幕后人。
- 口才：让船夫或押役补充细节；对方仍可能因害怕而隐瞒。
- 健康：低健康时不能同时完成桥头勘验和连续询问，只能委托差役补一项。
- 银两：可请船夫暂留、保全防水存根或安置受惊证人；不能买到马骁或清除本案压力。
- 声望/人脉：影响船夫、押役和覃保坤是否愿意给便利；冯天顺不进入本案。

本案不产生额外的全局系统状态。押役串供、马骁失踪和河埠路线只作为本案已经写明的事实与分支状态处理。

### 3.6 第一案自检

- 权限：通过。威达只查访、勘验、询问和提交建议；暂扣押役、封存凭照、移交责任由覃保坤及上级程序处理。
- 因果：通过。真实顺序是凭照被违规交接、马骁被带走、押役伪报翻车逃脱。
- 证据：通过。锁具/车辙、船夫、存根、凭照栏位和口供互相印证，没有单一证据包办结论。
- 选择：通过。两条路线分别保住责任链或外部交接链，并传入不同状态。
- 资源：通过。能力只改变时间、损失和证人配合，不生成真相；健康和银两有具体代价。
- 低资源：通过。低武力、低口才、没钱、低健康均可通过差役、书面材料或更慢路线继续。
- 信息边界：通过。只留下真实编号和局部外流事实，不揭示转收房上层或主线旧案。
- 待定：临时凭照正式名称与栏位的历史核验，列为 P2，不影响剧情自检。

**第一案结论：通过。**

## 4. 第二案：《空屋里的嫁妆》

### 4.1 差事入口与明确经济关系

卢小绫在成婚前夜失踪，嫁衣、首饰和钱物留在房中。舅父说她被夫家逼走，夫家说她私奔。地方衙门移文请求北镇抚司核验：有人持带北镇抚司编号的封验凭进入卢宅，试图封存房契和嫁妆清单。

经济关系固定如下：舅父欠钱庄一笔赌债，债主通过中人催收；卢小绫父亲留下的房契和小宅继承权属于卢小绫，舅父只有代管权，没有抵押或转卖权。中人想替债主取得房契原件，并逼舅父签下一份“以房契代管权抵债”的私契。该私契即使签成，也不当然有效，但会让卢小绫陷入长期争产和追索。中人使用凭照，是为了制造“官府即将查封”的压力，让舅父在恐慌中交出原件；中人不是网络核心，也不知道凭照来自谁。

### 4.2 局部外流链

- 一张封验凭已在百户所登记为待回收，但没有剪角；
- 原纸经内部转收房交给一名自称“代送封验文书”的文书，交接条只有职号；
- 文书把凭照交给债主的中人，并告诉他只可封存房契和嫁妆清单；
- 中人进入卢宅时，舅父和地方差役只看编号、蜡记和“封验”字样，没有核对本所回文；
- 中人拿走的不是房契本身，而是要求舅父交出原件并签私契；事后凭照被债主一方收回。

玩家只能确认凭照被外部人员用于民间施压，以及其中一个内部核验环节被绕过。

### 4.3 可验证事实

- 后院湿靛脚印和换鞋布包指向废染坊，证明卢小绫没有远走；
- 嫁衣夹层的父亲副契证明小宅继承权属于卢小绫；
- 舅父欠债簿记有婚期后三日的还款期限；
- 中人承认持凭照进入卢宅，但不能说明交付者姓名；
- 卢小绫说明舅父曾逼她交出房契，她愿作证但要求先保护副契。

### 4.4 玩家处理与不可逆后果

**先保护卢小绫和副契**：威达报告覃保坤，由覃保坤请地方衙门暂时守住柴房并按程序保护副契。卢小绫愿意说明舅父施压时间线；舅父会先去地方衙门反咬，凭照交付链变模糊。传入第三案的状态是“人证与副契完整，地方衙门承受舅父舆论压力”。

**先追查凭照使用者**：威达先查中人、封验时辰和交接地点，由覃保坤批准有限查访。玩家找到茶摊伙计和中人的交割条，凭照外部使用链更完整；卢小绫必须继续躲藏一夜，副契可能只能取得抄件。传入第三案的状态是“凭照链完整，卢小绫证词和副契完整度下降”。

玩家不能自行宣布凭照失效或强行带走舅父；任何传唤、暂扣和封存都由覃保坤、地方衙门或正式回文承接。

### 4.5 资源与养成作用

- 武力：保护转移中的卢小绫、阻止抢夺副契；低武力可请求差役协作但更慢。
- 智谋：把湿靛痕、布包、副契和欠债时间拼成两条不混淆的事实线：卢小绫藏身，以及凭照施压。
- 口才：让中人、茶摊伙计、舅父或地方书吏说出可核验细节；不让任何人自动认罪。
- 健康：低健康时只能优先保护人或追凭照一边；需要休养时由差役代办，舅父更易制造舆论。
- 银两：可租安全住处、买干粮药物、请脚夫转移或补办合法文书副本；无钱则依靠公门安置但更慢。
- 声望/人脉：公开办差声望影响地方人员的程序配合速度；卢小绫是否愿意当面对质只取决于玩家此前如何保护和对待她。

本案不产生额外的全局系统状态。舅父反咬、地方衙门抵触和凭照回收只作为本案已经写明的事实与分支状态处理。

### 4.6 第二案自检

- 权限：通过。威达协查凭照和文书，不裁判婚姻、房产权属或舅父其他罪责。
- 因果：通过。欠债、代管房契、中人施压和卢小绫藏身的利益关系已闭合。
- 证据：通过。湿靛痕、副契、欠债簿、中人证词和茶摊交割条各自证明不同环节。
- 选择：通过。先保人保住人证/副契，先追凭照保住交割链，分别造成不可逆损失。
- 资源：通过。能力改变保护、询问和证据整理成本；银两不能购买房契、真相或权限。
- 低资源：通过。没钱、低健康、低口才和低武力均有公门或差役替代路径，但更慢、更暴露或材料不完整。
- 信息边界：通过。只确认真实凭照被用于民间施压，不揭示转收房、魏承恩、景王或廖家旧案。
- 待定：封验凭的正式制度名称与地方协办权限的历史核验，列为 P2。

**第二案结论：通过。**

## 5. 第三案：《倒在更鼓前的人》

### 5.1 统一事实基线

本案唯一采用“程佑 / 冯六 / 夜行牌”版本。此前出现的“赵谨 / 罗魁 / 陈情”版本废弃，不得再写入章节、对白、证物或总簿。

城门小吏程佑在换更前死亡。赵培当晚确曾因赌债殴打过他，是地方衙门最先锁定的嫌疑人；但赵培离开后，程佑仍活着并继续值守。程佑发现一辆篷车使用的夜行牌与货载不符，准备记录并上报；门军小吏冯六收钱放车，后来回值房取回副联时与程佑争抢，用门闩击杀程佑。冯六随后参与补写和篡改值夜簿，把“货箱封签”写成“普通行人杂物”，让案件看起来只是赵培造成的斗殴致死。

冯六是直接行凶和篡改记录的人，但不是网络主人；网络只提供了被滥用的真实夜行牌和可利用的程序缺口。

### 5.2 局部外流链与五步时间线

夜行牌在本所被登记为错印待回收，原纸没有剪角；内部转收房把它交给一名持真实职号的代送文书，文书再交给篷车押运方。冯六知道这张牌不应当用于当前货载，却因收钱和惯例放行而接受。

五步时间线固定为：

1. **最后一次正常交接：** 三更前，程佑在城门值房登记货箱封签和篷车到达时间；这是值夜簿原始墨迹和货行封箱记录能证明的最后正常状态。
2. **直接冲突与死亡：** 三更后，赵培离开城门；冯六收钱放篷车，程佑发现货载不符并追到值房，争抢夜行牌副联时被门闩击杀。门闩血迹、冯六袖口松脂和伤口方向相互对应。
3. **文书被接触：** 冯六从程佑身上取走夜行牌副联，把副联藏进值房水桶夹层；副联撕口与水桶内纸片吻合。
4. **值夜簿被修改：** 冯六要求书吏补写“奉查验凭，取看随身杂物”，把原本的“货箱封签一批”改成“行人杂物”；补写墨色和原记录不同，书吏能说明自己受过什么要求，但不知道凭照来源。
5. **地方衙门形成初始结论：** 赵培的赌债票据、先前殴打和程佑死亡被拼成“斗殴致死”；直到副联、簿页和门闩证据互相对照，才推翻这一简化结论。

每一步至少有一项现场物证或证人，不能靠冯六自白补全全部时间线。

### 5.3 玩家处理与不可逆后果

**先固定现场和更鼓时间**：威达先核对血迹、尸体位置、值夜和更夫口供。玩家能证明赵培离开后程佑仍活着，保住直接死亡链；但冯六有时间销毁收钱字条，凭照改写链只能依副联和簿页推进。传入章末的状态是“死亡责任链完整，外部货物记号较弱”。

**先查案卷改动和凭照来源**：威达先核对副联、值夜簿、补写墨色和凭照记录。玩家能保住“货箱封签”被改成“行人杂物”的程序链，并找到书吏证词；现场拖痕和赵培不在场的细节会流失，地方衙门更久地把赵培当作唯一嫌疑人。传入章末的状态是“程序改写链完整，直接死亡链依赖地方记录”。

### 5.4 资源与养成作用

- 武力：保护更夫和书吏、阻止值夜簿被抢走、在获批协作下控制冯六；不能自行定罪。
- 智谋：排出赵培离开、冯六放车、程佑死亡、文书被取走和案卷被改写的顺序；不能直接指认网络上层。
- 口才：让更夫、书吏、货行和冯六说出可核验细节；不让任何人自动承认全部罪责。
- 健康：低健康时只能优先查现场或文书一边；必要时由城门差役代查，牺牲直接观察机会。
- 银两：可请更夫暂缓交接、安置书吏、复制残留记录或请脚夫确认篷车；无钱则走正式移文，证人和记录更易变化。
- 声望/人脉：公开办差声望影响地方人员执行正式协查的速度；书吏是否进一步配合只取决于玩家对他的具体处理。

本案不产生额外的全局系统状态。赵培被误认、冯六毁证和地方衙门抵触只作为本案已经写明的事实与分支状态处理。

### 5.5 第三案自检

- 唯一基线：通过。程佑、冯六、赵培、夜行牌、副联和门闩为唯一版本。
- 权限：通过。威达核验凭照和值夜记录；命案定性、搜查、拘押和移交由地方衙门、覃保坤及上级程序承接。
- 因果：通过。赵培制造误导，冯六造成死亡并篡改记录，凭照程序为掩盖提供便利，三者责任不混为一体。

- 选择：通过。先查现场保住死亡链，先查文书保住改写链，均造成章末材料差异。
- 资源：通过。属性改变取证成本与证人配合，不替代证据和地方命案程序。
- 低资源：通过。低武力、低口才、低健康、没钱都能以差役、书面记录和正式移文继续，但信息和时间代价不同。
- 信息边界：通过。只确认凭照让案卷变成另一种结论，不揭示转收房上层或景王。
- 待定：夜行牌正式制度名称、城门协查权限和地方搜查手续的历史核验，列为 P2。

**第三案结论：通过。**

## 6. 章末《失号凭照》总簿核验

### 6.1 正式入口与参与人

第三案证物移交后，覃保坤把三案回文、凭照原件/副联和证物清单呈交所属上级文书房，申请只核对三个编号的本所发放、核销和封存状态。上级批示限定查阅范围：本百户所的发放簿、核销簿、封存簿和三案证物，不得借此翻阅其他衙门总档或十五年前旧案。

核验由覃保坤主持，书记官负责抄录，库吏负责指认本所登记流程，廖威达只负责逐项比对已移交的三案材料。没有书面批示，威达不能自行打开总簿。

### 6.2 固定时间线

1. 三案证物移交当日，书记官把三张凭照分别装入证物袋，记录编号、纸种、蜡记和来源案件；
2. 次日上午，核验批示到达，覃保坤、书记官、库吏三人共同开簿，先记录封存状态，再比对三张凭照；
3. 三个编号分别属于押送、封验、夜行三种纸种，出库日期相隔数月；三张都被标记为“错印/待回收”，却没有剪角封存；
4. 三张领用条的字迹、日期和经手手印不同，不能把库吏直接定为主谋，但三张领用条都写明送至同一内部转收房；
5. 转收房收件簿恰缺三页。覃保坤让书记官先抄录相关页并盖印，随后由覃保坤封存原簿；
6. 当夜，封存记录显示封蜡被破坏，原簿缺页位置扩大，但盖印抄本、封蜡残痕和开簿记录仍在。玩家能证明总簿被人动过，不能证明具体是谁动手。

### 6.3 玩家能确认与不能确认

能确认：三张不同用途、不同地点、不同经手人的真实凭照，都在应当销毁的环节留下缺口，并经过同一内部转收房；有人能利用内部库存为外部人开门。

不能确认：谁控制转收房、三案是否服务同一个最终目的、魏承恩或任何王府人物是否知情、木牌是否与凭照有关、景王是否存在。

章末不可逆状态根据前三案选择变化：

- 押役原始口供是否完整；
- 卢小绫副契是原件还是抄件、她是否愿意继续作证；
- 程佑死亡链或案卷改写链哪一条更完整；
- 三案材料是否在核验前已由证人或对手部分毁损；
- 覃保坤、地方衙门和书记官对威达办差方式的判断。

这次核验不产生额外的全局系统状态。“凭照线索已被注意”是固定写入剧情的程序压力，为第三章继续追查转收房留下真实起点。
