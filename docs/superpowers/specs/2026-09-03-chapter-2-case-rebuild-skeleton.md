# 第二章案件重做骨架：失号凭照

状态：重做骨架，待玩家审核  
目的：在不改变第二章三案固定顺序、共同凭照机制和章末转收房结论的前提下，增强案件复杂度，并突出廖威达与覃保坤互补的办案特点。  
本稿不是正文，不直接进入代码。

## 一、不可改变的边界

- 固定顺序仍为：`雨夜失押` → `空屋里的嫁妆` → `倒在更鼓前的人` → 总簿核验。
- 三桩案子各自成立，直接犯罪者不同；共同点只在凭照被利用的程序缺口。
- 第二章不出现魏承恩、景王、廖家旧案、木牌来源和转收房上层控制者。
- 廖威达仍是校尉，负责查访、核验、询问、记录和执行已批准协查；不能自行越级搜查、定罪或调人。
- 覃保坤负责权限、秩序、人员分开看守、程序承接和责任担保；他不替廖威达得出案件结论。
- 三案仍要留下具体的互斥分支状态，供后续读取；不再用单一“已结案”抹平玩家选择。

## 二、两人的办案表现基线

### 廖威达

廖威达不靠长篇训话表现聪明，而是通过三个动作体现特点：

1. 把每个人的说法拆成“亲眼看见”“听别人说”“自己希望别人相信什么”；
2. 把时辰、路线、物件和行为排列成先后顺序；
3. 不急着认定幕后人，先确认哪一个环节确实被动过。

他的玩家选择主要决定调查顺序和证据取舍。即使判断错了，也只能损失时间、证人状态或某条证据链，不能让他突然说出没有依据的真相。

### 覃保坤

覃保坤不替玩家“提示答案”，他的特点通过现场处置体现：

1. 先把互相串供的人分开，把能保的原始记录先保住；
2. 看出不同人的顾虑：押役怕担责、舅父怕失房、中人怕债主、书吏怕卷入命案；
3. 对越权和毁证严厉处理，但不把所有人简单打成同谋；
4. 给廖威达调查空间，同时明确“出了程序问题由我担”；
5. 在结案时把不同责任拆开，不允许一个人用一句认罪包办全案。

两人不是师徒问答。廖威达负责发现和排列事实，覃保坤负责让事实有机会留下、让人按各自责任承担后果。

## 三、第一案《雨夜失押》

### 3.1 表面结论

马骁在暴雨夜押送途中逃脱。押役有翻车、锁扣和雨水冲痕作为表面依据；地方衙门希望尽快把案子定成“押役失职、嫌犯趁乱逃跑”，这样既不用追查真实去向，也不用追究谁批准了异常交接。

### 3.2 实际结构

本案不是单纯的“押役合谋”。三个人各自隐瞒一部分：

- 押役甲确实收过钱，但只负责在翻车后不回拨核验；
- 押役乙没有收钱，却在看见篷车接人后选择不说，因为他怕被追究擅离押送岗位；
- 河埠船夫看见有人带马骁离开，但把“有押役同行”误认为合法转押，不愿卷入官差争议。

真正的关键不是谁把马骁押走，而是有人利用真实凭照和押役的恐惧，让一次非法转移看起来像正常交接。

### 3.3 调查层次

**第一层：翻车是否真实。**

廖威达发现车辕折痕方向和押役口供不符，锁扣没有从内侧挣脱痕迹，车厢内却有拖擦痕。覃保坤不立即抓押役，而是命人把两名押役分开，先固定各自看到的部分。

**第二层：马骁从哪里离开。**

车辙、船夫和茶棚伙计分别提供不同时间点。船夫只看见篷车，茶棚伙计只记得一个别号；任何单独口供都不足以证明完整路线。

**第三层：凭照为什么能让人放行。**

凭照编号、蜡记和押送纸种真实，但领取人和终点栏为空。廖威达判断这是“真凭照被用于假交接”，覃保坤则提醒他：这只能证明流程被绕过，不能直接证明内部有人下令。

### 3.4 关键人物表现

- 廖威达会追问押役“你亲眼看见了什么”，逼出“看见马骁站起来，但没看见他跑”的差别。
- 覃保坤会当场斥责统一口供的押役，但只按隐瞒、失押和毁坏存根分别记录，不逼他们承认不存在的上层关系。
- 当船夫害怕时，廖威达不许差役用身份威胁；覃保坤改用“只记你亲眼见到的，不让你替官府背结论”的办法，让船夫留下证言。

### 3.5 玩家分支

**A：先固定押役责任链。**

- 廖威达保住两份互相矛盾的原始口供、锁具记录和翻车现场；
- 覃保坤据此把押役责任正式拆开处理；
- 河埠路线只剩模糊方向，马骁外部去向难以继续追；
- 状态：`c2_01_responsibility_chain`。

**B：先追河埠交接链。**

- 廖威达追到船夫、茶棚伙计和领取别号，确认凭照如何让篷车离开；
- 覃保坤只能先把押役列为待核，无法立即固定全部责任；
- 押役的第二份口供被统一过，后续只能依现场和存根拆穿；
- 状态：`c2_01_route_chain`。

### 3.6 结案留下的思考点

玩家可以确认“马骁不是自行逃跑”，但不能确认谁安排了转移。廖威达在案尾把凭照上的空栏圈出；覃保坤只说：“空着的地方，往往比写满的地方更麻烦。”

## 四、第二案《空屋里的嫁妆》

### 4.1 表面结论

卢小绫在婚前失踪，舅父声称她私奔，夫家声称她被舅父逼走。持封验凭的人进入卢宅，要求取看房契和嫁妆清单。地方衙门倾向把它当成家产争执，不愿承认有人借官府凭照施压。

### 4.2 实际结构

本案必须保留一个真正的不确定点：卢小绫确实主动躲起来过，不是完全被动受害者。她这么做，是因为发现舅父准备把父亲留下的房契作为赌债抵押；但她没有告诉任何人自己把副契藏在哪里。

同时，舅父不是幕后组织者。他欠债、想保住房子，也确实签过一份不合理私契；中人则利用封验凭制造“官府即将查封”的压力。三方各自有过错，但只有中人实施了凭照冒用和强迫交割。

### 4.3 调查层次

**第一层：卢小绫是逃走还是被带走。**

湿靛脚印、换鞋布包和后院缺失的嫁衣配件说明她自行从后门离开；但她留下的副契和被撕破的衣带又说明离开前发生过拉扯。

**第二层：舅父是否有动机。**

赌债簿写明还款期限，舅父确实有动机；但茶摊伙计见到中人持凭照进入，说明“舅父有动机”不等于“舅父安排了冒用凭照”。

**第三层：封验凭的作用。**

封验凭没有查封效力，却足以让舅父和邻人误以为官府已经介入。廖威达要把“官府凭照被冒用”和“房产纠纷本身”拆成两条线。

### 4.4 关键人物表现

- 廖威达不会因为卢小绫主动藏身就把她判成撒谎者，而是区分她隐瞒藏身处和她遭受逼契的事实。
- 覃保坤看出舅父最怕的不是坐牢，而是房契被拿走后彻底失去翻身机会；他让差役先封存房契，再处理舅父的赌债责任，防止人证和产权问题混成一团。
- 中人试图把所有责任推给“上面”，覃保坤当场打断：“你只说你拿了什么、进了谁家、要了什么。上面不是你的免罪牌。”

### 4.5 玩家分支

**A：先保护卢小绫和副契。**

- 廖威达先核验副契、脚印和卢小绫陈述；
- 覃保坤安排地方衙门守住藏身处，并让书吏把副契按原件封存；
- 舅父抢先去衙门反咬百户所藏人，中人趁乱离开；
- 状态：`c2_02_witness_deed`。

**B：先追封验凭交割链。**

- 廖威达先追中人、茶摊伙计和凭照交割时辰；
- 覃保坤让地方衙门暂缓公开房契争议，避免中人得到警讯；
- 卢小绫的副契在藏匿过程中受潮，只取得抄件，证词也更谨慎；
- 状态：`c2_02_receipt_chain`。

### 4.6 结案留下的思考点

玩家可以确认：封验凭能制造官府压力，却不能凭空改变房产权属。廖威达在案尾把“凭照冒用”和“舅父逼契”分栏记录；覃保坤提醒：“一个人做错两件事，不代表两件事是同一拨人让他做的。”

## 五、第三案《倒在更鼓前的人》

### 5.1 表面结论

程佑死在城门值房。赵培此前因赌债殴打过他，地方衙门因此先认定是斗殴致死。冯六是门军小吏，承认自己当夜放过一辆篷车，却坚持说程佑是被赵培打伤后才死的。

### 5.2 实际结构

本案的复杂度来自三种不同的谎言：

- 赵培隐瞒自己离开后又折返过城门外，但没有进入值房；
- 冯六隐瞒收钱放行、与程佑争抢副联和篡改值夜簿；
- 书吏隐瞒自己曾按冯六要求补写记录，因为他怕被视为共犯。

冯六是直接造成死亡和改簿的人，但夜行牌只是被滥用的程序工具，不把所有责任推到凭照来源上。

### 5.3 调查层次

**第一层：死亡时间。**

更夫证明赵培离开后程佑仍敲过一次更鼓；尸体拖痕、门闩血迹和伤口方向指向值房内冲突。

**第二层：副联去向。**

夜行牌副联藏在值房水桶夹层，撕口与水桶内纸片吻合。它证明冯六接触过凭照，却不自动证明他杀人。

**第三层：案卷为什么改变。**

值夜簿把“货箱封签”改成“行人杂物”，补写墨色不同。书吏承认被要求补写，但只知道要求来自冯六，不知道冯六从何处拿到夜行牌。

### 5.4 关键人物表现

- 廖威达把当夜划成五个时刻，不允许任何人用“差不多就是那会儿”带过关键空档。
- 覃保坤把赵培、冯六和书吏分开处理：赵培的斗殴另案处理，冯六的命案和毁证分开记录，书吏的补写行为按是否主动参与判断。
- 冯六试图用“我只是收钱放车”减轻命案责任，覃保坤不接受，也不逼他承认上层命令，只说：“你做的每一步，先按你自己的手印算。”

### 5.5 玩家分支

**A：先固定现场和更鼓时间。**

- 廖威达保住尸体位置、门闩血迹、更夫口供和赵培离开时刻；
- 冯六有时间烧掉收钱字条，案卷改写链需要后续补证；
- 状态：`c2_03_death_chain`。

**B：先查案卷改动和凭照来源。**

- 廖威达保住副联、补写墨色、书吏陈述和原始货行封箱记录；
- 值房拖痕被踩乱，赵培离开后的直接现场细节减少；
- 状态：`c2_03_record_chain`。

### 5.6 结案留下的思考点

覃保坤在结案时明确拆分：“命案按命案办，毁证按毁证办，凭照滥用另记。别因为一页纸，把三个人的手写成一只手。”

玩家确认的是：有人利用夜行牌和案卷缺口改变了一个命案的解释，但仍不知道这张凭照从哪里流出。

## 六、章末总簿核验的角色表现

三案结束后，覃保坤主持本百户所内部核验。廖威达负责逐项比对三案材料，不能自行打开其他衙门总档。

这段要突出两人的差异：

- 廖威达发现三张不同纸种的凭照都被标为“错印/待回收”，却没有剪角，并把三案的证据缺口逐项写入附录；
- 覃保坤先让书记官抄录原簿前后页，再封存总簿，不因发现共同转收房就立即抓库吏；
- 当封蜡被破坏、缺页扩大时，覃保坤第一反应是保护抄本和经手记录，而不是追一个暂时没有证据的人；
- 廖威达提出“这不是三次偶然”，覃保坤回答：“可以写成疑点，不能写成结论。”

章末确认：三张不同用途的真实凭照，都在应当回收的环节留下缺口，并经过同一内部转收房。玩家知道程序被利用，但不知道谁控制它、三案是否服务同一目的，也不知道它与廖家旧案是否有关。

## 七、重做骨架自检

- **案件差异：通过。** 第一案是押送链和多人分段隐瞒；第二案是主动藏身、房契利益和官府压力；第三案是死亡时间、毁证和案卷改写。
- **人物表现：通过。** 廖威达通过拆口供、排时间和分证据体现特点；覃保坤通过分开处理、控制程序和承担责任体现特点，不替玩家破案。
- **选择后果：通过。** 每案两条路线保住不同证据，并造成具体、不可逆的人证或现场损失。
- **权限：通过。** 廖威达没有自行搜查、定罪、越辖或调军；覃保坤的动作符合百户所程序承接范围。
- **主线边界：通过。** 没有提前出现魏承恩、景王、廖家旧案或木牌来源。
- **跨章状态：通过。** 三案分别写入六种互斥证据状态，章末共同转收房结论仍由总簿核验产生。
- **低资源：通过。** 低武力、低口才、低健康或缺钱只改变证人配合、时间和证据损失，不阻断结案。
