# 全游戏章节结构设计

日期：2026-08-24  
状态：总章节数量与阶段分配已获玩家确认；各章具体流程待设计  
范围：完整游戏的章节数量、主线阶段分配与章节级高潮位置。不定义每章的具体案件文本、玩法数值、分支、角色命运或代码。

## 1. 已确认总结构

完整游戏采用：**序章 + 正式五章**。

序章不作为独立的长篇主线章节，采用“有限全景 + 幼年主观”的镜头：先让玩家看见廖宅被围、各处起火与逃散的家仆，再回到三岁廖威达所经历的火光、混乱、被带离与被留在村口。全景不展示身份、命令、组织归属或可追踪的阴谋信息。

五个正式章节共同完成从新校尉入职到景王现形的完整流程。章节不是按“收集一条线索”机械切分；每章都必须有可独立成立的办案目标、人物压力、阶段性收获或损失，以及一个将玩家带向下一章的未解问题。

## 2. 五章分配

### 第一章：火后余烬

- 覆盖：入职、《纸灰里的银子》、烧焦木牌出现。
- 阶段作用：让玩家先作为北镇抚司校尉完成一桩独立案件；木牌只作为无法解释的异常物被保留。
- 章末问题：木牌原本标识什么，为何经历旧火后又被刨去牌面？

### 第二章：失号凭照

- 覆盖：三起独立碎案《雨夜失押》《空屋里的嫁妆》《倒在更鼓前的人》，以及《失号凭照》的第一次串线。
- 阶段作用：从不同性质的案件中确认，本应作废的真实内部凭照被人在外部滥用；通过本百户所的总簿确认它们都经过同一内部转收房。
- 章末问题：谁能使本应销毁的内部凭照持续流出？

### 第三章：看见节点

- 覆盖：从转收房、被篡改记录与后续案件追向魏承恩，形成对锦衣卫内部高层的调查、行动和落网。
- 阶段作用：提供一次真实阶段胜利。魏承恩确实参与网络、知道景王并参与旧案清理，不是误抓的替罪羊。
- 章末反转：魏承恩落网后，网络中的包件、人手和手续仍在既有程序中继续流动。

### 第四章：旧火未尽

- 覆盖：魏承恩倒台后的接管痕迹、木牌来源确认、廖宅火后处理与当前机制合拢；李慕尘作为关键执行层人物在一桩后期案件中被事实查出。
- 阶段作用：让廖承志、廖宅灭门与当前案件真正汇合，确认父亲当年碰到的是同一长期机制的一部分。
- 章末问题：魏承恩不是主人；谁能够让这张网在一个高层倒下后仍无声运转？

### 第五章：主人现形

- 覆盖：多层证据的汇合、可公开追究的程序、景王对网络的最终控制与谋反目的揭露。
- 阶段作用：兑现个人旧案、案件事实链、人物关系与权力网络。景王必须由相互咬合的证据逼出，不能由口供、密信或突然公布名单解决。
- 结局边界：本章需要在后续设计中明确玩家选择、损失与最终公开路径；当前不预设具体结局文本。

## 3. 章节级逻辑自检

- 第一章只引入异常物，不提前让木牌与廖宅、景王或网络绑定。
- 第二章的三案各自独立闭合，串线来自主角职权内的凭照总簿核验，避免以重复模板或越权调档代替推理。
- 第三章中魏承恩是有真实责任的高节点，因此抓捕具有胜利感；第四章网络继续运转不是推翻第三章事实，而是证明魏不是主人。
- 第四章单独承受旧案合拢与李慕尘查出的情感重量，防止与景王终局挤在同一章而削弱两次高潮。
- 第五章只负责最终证明与追究，不再承担木牌来源确认或首次揭开廖宅旧案的工作。
- 序章加五章的长度为玩家保留案件、关系与养成空间，但不额外拆出一章没有主线落点的“纯碎案章节”。

## 4. 后续设计顺序

1. 逐章设计每章的玩家目标、案件顺序、人物进入时机、选择与可见后果。
2. 将健康、银两、能力与人脉嵌入案件，确保每项资源均改变可用手段、代价或后果。
3. 完成章节级对抗审查。
4. 玩家确认完整章节设计后，才进入实施计划与代码重做。
