# 第三章修复方向：对抗式逻辑审查

以下只列会使修复方案失效的缺口，不视为替方案或总结。

## 1. 违法性成立条件不足

- “已具名复核证人不得改接收处、延长留置”只有程序规则，没有写明原留置的法源、期限、到期释放/移交动作，也没有规定谁负责在到期时强制纠正。若这些要件缺失，改接收处可被解释为安全调度，延长留置也无法计算出逾期时点，阻碍复核的违法性不能仅凭叙事宣告成立。
- “指挥使不得以普通督办手令替代复核更令”未区分命令的签发权限、送达和效力。若指挥使对本系统本来有内部调度或看押权限，普通手令可能仍足以合法改变执行方式；文本没有规定何种事项必须由何级复核令批准，故违法属于作者设定而非可被玩家证明的事实。
- 强迫库吏签“覃保坤失职”可能是胁迫取供、行政处分陈述或内部说明，三者法律后果不同。未设非自愿陈述的排除规则、见证、讯问记录和伤情/压力证明，不能稳定定性为违法取供。

## 2. 魏承恩仍可推责

- 亲签命令只证明他签发或被登记为签发人，不证明他知道库吏被挡在复核处、知道留置被延长，或亲自提出“签陈词才移交”的条件。命令可被解释为例行调度、误签、代签或被下属利用。
- “覃保坤失职”陈词由库吏提交，魏可主张是库吏自行归责、下属执行过当；没有能把条件、现场口令和魏的知情串在一起的独立证据，责任会落到中层执行者。
- 若魏有权对百户所进行督办，指挥链中的下属越权不必然归责于魏；需证明他明知违法仍维持或追认，而现方向未定义追认记录、回报或拒绝纠正的节点。

## 3. 文书真实性与独立性不足

- 原令、副本、用印记录“分机构保管”不等于独立制作。若递运所、原发机构和印房均受魏控制，三份材料可以协同伪造；没有出号簿、递送见证、封套连续号、落款笔迹/印色检验和冲突版本的优先级规则。
- 同号副本如果没有明确“副本”标记及复核程序，会造成编号复用：任何一份都可被主张为原件，无法判断哪一文本在何时生效。
- 递运所登记“收到”只能证明收件簿上有记录，不能证明实际见到证人、交付了何种状态或接受了何种限制；接收条件的描述和见证人若由同一执行链填写，仍是单方自证。
- 库吏半份陈词与副本附文逐字对应，首先证明的是抄写模板或诱导，不是库吏真实陈述。半份的物理含义（撕半、只签一段、未完稿）不明，不能据此推断签署范围和完整性。
- 留置记录只证明“记录了执行结果”；记录人、制作时点、是否补记、是否受魏控制均未分离，无法排除事后补录或把未移交写成已执行。

## 4. 玩家权限会被预授权条款抬高

- 廖威达的限案差牌把“查本次移交、保护证人、封存记录、申请搜救”一次性写入，但触发条件“证人未按令抵达”可涵盖迟到、拒到、转押、被劫和文书错误。没有时限、地域、对象和武力边界，玩家可能凭一句迟到直接搜查、封存或调动外部人手。
- “封存相关记录”与第二章既定边界冲突：威达只能查访、核验并建议，封存由覃保坤/上级程序承接。若差牌本身已授权封存，玩家身份就被隐性升级，前后权限不一致。
- “申请搜救”未指明受理机关和批准人；递运所、地方衙门、北镇抚司之间谁能进入谁的辖区、谁负责实际搜救没有闭合。玩家可能既无执行权，也无可操作的失败路径。

## 5. 发现顺序与第二章承接断裂

- 第二章只把玩家带到“作废凭照经过同一转收房”，未给出具名证人、复核地点或魏承恩姓名。从转收房直接出现魏亲签命令是高层跳跃；中间缺少能合法取得命令副本、确认签发链并排除其他经手人的事件。
- 若玩家先拿到魏签令，再追查证人，证据顺序变成先知结论；若先追证人，限案差牌又未授权读取跨部门命令，玩家无法自然获得签令。两条发现路径当前都缺少权限和触发条件。
- 第二章总簿已有“缺页、破蜡、抄本”脆弱性。新章仍依赖分机构文书而没有说明为何这次未被同样替换，会让前章的篡改风险失去连续性。

## 6. 外部处置权限与等待风险

- 指挥使涉案后“内部保全、封缄直呈”没有指定有资格直呈的主体、密封物交接和回令时限。普通校尉不能当然绕过层级直达皇帝，玩家也不能自行代表机构奏报。
- 等御封回令期间，魏仍掌握人事、印信和下属，能够毁证、转移证人或反向拘押保全者；方案没有临时停职、隔离、外部看押和安全失败状态。
- 御封回令即使授权解除职务、收印、封存房署，也不自动授予执行者审讯或定罪权限。“押审”把逮捕、羁押、审讯、移交和审判混成一个动作，缺少承接衙门及合法拘押地点。
- “直呈”若被魏控制的印房加封，回令真实性、编号和送达也可被伪造；没有独立核验渠道，玩家无法确认回令何时真正到达。

## 7. 动机与章末反转会稀释责任

- 魏为何在已引发三案总簿核验后亲自留下可追踪签名、还要制造指向覃保坤的陈词，没有与第二章暴露的具体风险、包件或人事冲突绑定。若只是保护网络，亲签并非唯一或最隐蔽手段，动机显得为交付证据服务。
- 把责任写成“覃保坤失职”需说明覃掌握了什么、为何可被归责；否则陈词与魏所保护的转收链无直接关系，只是随机甩锅，不能证明魏参与旧案清理或现案滥用。
- 只冻结涉案线路而让魏被押前已完成的无关旧调拨继续流转，若该线路共享同一库吏、印房、递运所或包件，所谓“无关”无法客观划定，既可能放走涉案证据，也可能让玩家误以为魏仍远程控制。
- 若无关线路确实完全独立且能自动继续，魏被捕后的持续运转反而削弱其高节点责任：网络不需要他的权限即可完成同类操作。若仍需其人事/印信资源， selective freeze 又与“只冻结涉案线路”矛盾。
- 章末反转若只展示手续继续流动，没有保留下魏对具体节点的不可替代决策或利益收益，魏会退化为可替换签字人，第三章的“真实阶段胜利”不足。
