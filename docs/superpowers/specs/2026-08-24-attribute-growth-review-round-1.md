# 属性与养成系统：专门审查第一轮记录

日期：2026-08-24  
审查范围：`2026-08-24-attribute-growth-system-design.md` 的有限行动、成长路线、事件差异、健康、风险、银两与主线兼容性。  
审查方式：专门子智能体对抗审查；本记录不改写任何剧情或数值。

## 初审结论

方向通过，但当时不准进入实施计划。初稿存在 3 项 P0 和若干 P1：

| 严重度 | 问题 | 已采取的修订 |
|---|---|---|
| P0 | 普通闹市事件“暗中观察”会增加风险，违反风险只能代表旧案暴露的定义 | 改为犯人警觉和后续追捕变化；明确普通事件不能使用旧案风险 |
| P0 | 健康只有概念性阶段，缺少行动限制、恢复和代价闭环 | 增加四个健康状态及每一状态的可见限制和恢复代价 |
| P0 | 风险缺少来源、阶段、反制与应对闭环 | 改为按旧案调查对象记录的暴露档案，增加四阶段信号、敌方行动和玩家应对 |
| P1 | 成长来源和反刷取边界不够可执行 | 增加能力成长来源表、事件链状态、章节上限、演变规则和收入限制 |
| P1 | 主副路线只是描述，无法防止全属性同时高阶 | 改为经历记录加阶段应用；有限行动与章节开放共同限制同步成长 |
| P1 | 五项能力缺少可感知阶段差异 | 增加基础校尉能力、复杂应用和不可替代内容的对照表 |
| P1 | 月度三行动与第一章两日主案的时间关系未定义 | 明确主案独立案件时钟，不额外发放或暗扣自由行动 |

## 尚待后续章节设计验证的项目

以下项目不能在没有第二至第五章案件细节时伪造为“已验证”，被列为后续章节设计与全流程审查的硬门禁：

- 每个核心事实至少两条可验证取得路径；
- 每条替代路径的授权来源、时间损失、失败后果和跨章保留状态；
- 低健康、高风险、低银两、关系受阻在具体案件中仍可继续的路径；
- 每章是否存在唯一最优的培养方向；
- 升迁后新增正式权限与能力应用的边界。

## 当前阶段结论

属性与养成总设计的系统规则已具备进入“第一章养成嵌入修订”的基础，但不是实施计划，更不是代码准入。第一章整合后应以该章具体选择、资源、证据链和案件时间表进行一次场景级复核；第二至第五章完成后再做全流程审查。
