# 第一章《纸灰里的银子》可玩性重塑规格

日期：2026-09-09  
状态：待玩家审阅  
范围：第一章纸铺案的调查、核验、人物交锋与结案玩法；不涉及第二章及后续章节。

## 1. 目标

将当前“选择一段文字后自动汇总真相”的流程，重塑为一段由玩家亲自观察、取证、核验、修正判断并提交结案意见的锦衣卫办案体验。

本章通过后，将其玩法密度、证据反馈、人物参与和实现质量作为后续章节的最低标准。

## 2. 已确认方向

采用“证据推理为主、人物交锋与程序请示为辅”的混合型玩法。

核心循环：

```text
明确待证问题
→ 现场观察
→ 选择调查手段
→ 获得局部证据或证词
→ 对照矛盾并形成怀疑
→ 向覃保坤请示权限行动
→ 夜间保全一项办案条件
→ 第二日补证与人物交锋
→ 提交结案判断
→ 覃保坤依法处置并评价
```

## 3. 默认假设

- 沿用现有 React 应用、新章节状态机、存档机制和第一章视觉外壳。
- 不新增通用风险、月份、日常循环、自由行动窗口或复杂小游戏。
- 本案证据、证词和办案记录可以使用第一章局部结构，但不擅自扩展为全局系统。
- 不新增未经确认的人物关系字段；人物差异先通过场景反应和结果文本表达。
- 玩家判断错误时允许补正，不以一次错误选择锁死案件或主线。
- 关键图片继续使用现有路径和替代文本；缺少新素材不能阻断玩法。

## 4. 不变事实与边界

- 纸铺案在第一章独立结案。
- 吴生最终洗脱嫌疑；贺兴因侵吞、纵火和栽赃被移交。
- 廖威达只执行查访、勘验、核验、整理与提出建议；封存、调人、暂扣和主持复核由覃保坤决定。
- 第一章结束必须写入：`first_case_closed`、`charred_token_preserved`、`tianshun_reconnected`。
- 烧焦木牌不帮助侦破纸铺案，只作为经历旧火且被人为抹去身份的异常物入档。
- 不出现第二章以后人物、李慕尘真实身份、廖家旧案真相或景王信息。
- 第一章不设置自由行动窗口，不改变全篇七个自由行动窗口的数量。

## 5. 玩家待证问题

进入纸铺后，案件记录明确列出三个尚未回答的问题：

1. 吴生为什么拿着装有散银的工作包从后门出来？
2. 火为什么先烧向内部记录和印纸存放处，而不是最易燃的库料？
3. 失窃印纸是否真的全部毁于火中？

这些问题只陈述矛盾，不预告贺兴是真凶。

## 6. 第一日调查

第一日提供三条调查路线，玩家只能优先完成其中两条。每条路线至少包含一次观察或核验判断，不能点击后直接发放整条结论。

### 6.1 送样路线

可取得材料：送样凭条、邻铺说法、脚夫证词。

玩家需要判断：地址不存在能证明“吴生被支开”，但单独不能证明是谁写下假地址。进一步固定脚夫关于交付者的记忆，才能把凭条与贺兴的经手行为联系起来。

### 6.2 火场与后库

可取得材料：起火位置、集中拖拢的纸页、断绳或包装残片。

玩家需要判断：起火点说明纵火者优先想毁掉什么；残片则可能用于第二日核对失窃印纸。危险清障和正式封存必须经过覃保坤批准。

### 6.3 客户副联与数量

可取得材料：客户副联、上级差牌、纸铺内部记录中的数量缺口。

玩家需要判断：副联能证明预付款和印纸曾进入纸铺，但不能单独证明贺兴纵火。只有与内部经手记录、火场位置或包装编号组合后，才能固定动机和操作痕迹。

### 6.4 第一日最小结论

玩家最多只能合理得出：

- 吴生并非主动离铺；
- “吴生偷银后纵火”的现有说法不能解释全部事实；
- 仍缺少谁接触工作包、谁毁记录以及印纸去向的完整证明。

覃保坤可以指出证据边界，但不得替玩家宣布贺兴有罪。

## 7. 证据核验方式

证据玩法采用轻量命题核验，不制作拖拽拼图或复杂案件板。

玩家面对一个待证命题，从已取得材料中选择支持它的依据。系统需要区分：

- 直接支持：足以推进当前判断；
- 相关但不足：方向有关，尚不能证明命题；
- 相互冲突：提示玩家重新检查说法；
- 尚未取得：不能被界面提前泄露。

错误选择不扣隐藏数值。覃保坤或案件记录说明“这件材料目前只能证明什么”，玩家可以重新提交。

## 8. 覃保坤的玩法职责

覃保坤不是答案提示器，也不是单纯的流程按钮。他需要：

- 追问玩家为何作出当前判断；
- 明确指出材料的证明边界；
- 根据玩家调查顺序，对其急躁、稳妥、看人或重物证的倾向作出具体评价；
- 在需要封存、差役协作、公开复核或暂扣时行使百户权限；
- 以短促、具体的言语和市井经验观察涉案者，但不代替玩家完成关键推理；
- 在玩家提交错误结论时要求补正，并承担最终程序责任。

## 9. 夜间取舍

夜间只选一项，且必须改变第二日可见内容或办案成本：

| 选择 | 直接所得 | 第二日影响 |
|---|---|---|
| 整理证物与笔录 | 将已取得材料整理为复核次序 | 少做一次重复核验，但威达表现出疲劳 |
| 看望吴生 | 得到他折返时看见贺兴从后库出来的细节 | 吴生愿意当面对质，人物交锋更稳定 |
| 守住火场残料 | 保住带包装编号的残片或半页烧账 | 获得更完整物证，但消耗既有银两 |

任何选择都不能成为唯一正确答案。缺失材料必须存在逻辑明确、成本不同的替代证明路径。

## 10. 第二日补证与人物交锋

第二日首先围绕第一日遗留的关键缺口补证。随后玩家选择向贺兴展示或暂不展示已掌握的材料，并决定追问顺序。

人物交锋遵守以下规则：

- 单项证据不足时，贺兴可以给出表面合理的解释；
- 两项互相咬合的证据可以暴露其说法矛盾；
- 完整证据组合不依赖贺兴自白，也能支持移交；
- 吴生是否愿意当面对质，取决于夜间是否看望及玩家此前是否把他只当作既定嫌犯；
- 覃保坤主持追问和程序处置，廖威达负责提出矛盾与依据。

## 11. 结案提交

结案不再由到达节点后自动完成。玩家必须提交：

1. 责任判断：谁实施了侵吞、纵火和栽赃；
2. 关键依据：选择两至三组能够互相印证的材料；
3. 处置建议：当众复核，或暂不点破继续追问。

若责任判断或证据组合不足，覃保坤指出缺口并允许补正。处置建议不存在绝对正确答案，但会改变：

- 贺兴是否补充说法；
- 遗失账页能否追回；
- 吴生与纸铺额外承受的时间压力；
- 覃保坤对廖威达本次办案方式的具体评价。

两种合格处置最终都能依法结案并写入既定状态。

## 12. 玩家可见反馈

案件记录只显示玩家已经知道的内容，分为：

- 待证问题；
- 已取得材料；
- 已固定事实；
- 尚存缺口；
- 当前请示或处置建议。

界面不得提前展示未调查证据、幕后真相、隐藏最佳路线或内部状态名称。

## 13. 测试策略

实施必须测试先行，至少覆盖：

- 第一日只能完成两条优先调查；
- 三条路线写入不同材料，而非立即写入完整真相；
- 未取得的证据不能用于核验；
- 相关但不足的证据不会错误固定事实；
- 三种夜间选择产生不同第二日状态；
- 每条夜间路线都有可完成案件的替代证明路径；
- 不合格结案提交会被要求补正；
- 两种合格处置都能写入 `first_case_closed`；
- 木牌与冯天顺状态仍按既定顺序写入；
- 存档恢复后保留调查进度与已固定事实。

## 14. 可玩性验收标准

自动验证通过后由玩家实际试玩。第一章通过门禁需同时满足：

- 可玩性评分由当前 15/50 提升到至少 35/50；
- 玩家能复述自己如何排除吴生并锁定贺兴，而不是只复述旁白答案；
- 至少一次选择明显改变后续证据、人物反应或办案成本；
- 覃保坤的特点通过互动可被感知；
- 玩家能感受到查访、勘验、核验、请示和处置之间的锦衣卫办案边界；
- 玩家认为结案来自自己的判断，而不是自动播放的剧情。

## 15. 本轮不做

- 第二章或后续章节开发；
- 通用自由行动菜单；
- 新的全局数值、风险或人物关系字段；
- UI 视觉风格重做、移动端适配或 PWA；
- 新图片、音乐或外部素材生成；
- 复杂拖拽案件板、随机真凶、战斗或审判模拟。
