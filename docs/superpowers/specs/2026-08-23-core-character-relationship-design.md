# 核心人物关系与信息边界设计

日期：2026-08-23  
状态：人物关系审查通过；待进入章节案件设计  
范围：核心人物之间的关系、职责、知情边界与合理接触门槛。本文不定义具体案件、完整证据细节、数值系统或代码改动。

## 1. 目的

主线《一张看不见的网》依赖人物各自只掌握一部分事实。网络不能因为角色直接见面就变成全员知晓景王谋反，也不能让低阶校尉无代价接触权力高层。

本文固定以下原则：

- 角色拥有独立目标、关系、恐惧和行动逻辑，不是主角的任务入口。
- 直接接触不等于共享全部信息。
- 廖威达的关键判断与取舍由玩家决定；人物设定只约束前史与无选择场景的默认呈现。
- 旧案知情者可以掌握局部事实，但不能前期替玩家说出景王或完整网络。
- 后续案件必须遵守本文的权限与信息边界；发现冲突时先向玩家说明，不得暗改基线。

## 2. 关系结构

```text
景王
├── 孙玉堂：王府管家，知道谋反，负责王府层钱、人、外部关系与善后
├── 魏承恩：锦衣卫高层，知道景王是最终主人，负责锦衣卫体系内的案件与人事
│   └── 杜文昭：早年受魏提拔，现为东厂高层；负责东厂侦缉和强制处置
└── 沈敬亭：商人层，处理资金与商路；只知上面有人，不知景王

廖承志旧案
├── 周寒川：廖承志好友，知道调查方向与灭门关联，但不知景王
├── 李慕尘：执行层剑客，参与灭门并救走廖威达；不掌握旧案全貌
└── 廖威达：玩家主角，后期由案件事实逐步重建全貌
```

## 3. 主角与前期关系

### 廖威达

- 十八岁，北镇抚司校尉，靠自身努力进入锦衣卫，不是周寒川保送或安排入职。
- 三岁经历廖家灭门。长大前只知道父亲是锦衣卫，不知道父亲调查内容、灭门原因和参与者。
- 默认气质为沉默寡言、心思缜密、冷静、情绪稳定；关键案件、关系和价值选择由玩家决定。
- 作为普通校尉，不具备独立调人、越级查档或随意接触御史、王府管家、东厂高层与锦衣卫高层的权限。

### 覃保坤

- 廖威达直属百户，承担前期日常差事、程序约束和功劳分配。
- 初期只知道周寒川托其留意一名新人，不知道廖威达是廖承志之子，也不知道廖家灭门案。
- 其与主角的关系必须由共事和相互观察形成，不能成为周寒川或旧案的替代说明者。

### 冯天顺

- 廖威达儿时唯一的同龄兄弟，爽朗、嘴快、直来直去，来自普通而热闹的村中家庭。
- 不知道廖家、廖承志、灭门案或周寒川掌握的旧案事实。
- 不作为可重复刷取情报、好感或武力资源；只在正常生活、军中身份或具体案件自然需要时进入。

## 4. 廖家旧案关系

### 周寒川

- 廖承志好友，知道廖承志当年正在调查一条涉及资金、利益和权力保护的线，也知道廖家因调查而灭门。
- 不知道景王是最终主人，也不知道完整的执行、掩盖和受益链。
- 廖威达成年后，周寒川先因外貌与廖承志相似而起疑；再见到其灭门前随身携带、刻有“廖威达”本名的旧物，并结合年龄与旧交记忆确认身份。
- 这一确认过程必须在主线中逐层体现：前期异常反应，中期让玩家意识到其早有怀疑，后期进入旧案时才说明确认依据。周寒川不能因此提前讲出全部真相。
- 确认身份后会更加关注廖威达，但既不能替其入职，也不能取代玩家作出办案与价值判断。

### 李慕尘

- 景王之网执行层的剑客，受命参与廖家灭门；不知道廖承志调查的全貌、景王的最终主人身份或完整王府安排。
- 灭门夜见到三岁的廖威达，一时恻隐将其救出并留在村口，随后离开。此后不知道孩子是否活下来，也未寻找、照顾或暗中保护。
- 大火烧毁现场尸体、物件与痕迹，其他执行者因此认定孩子已死；景王之网不知道有幸存者。
- 李慕尘继续留在原执行势力，凭办事能力与剑术上升。他不是赎罪者、常驻伙伴或旧案答案提供者。
- 成年后主角与李慕尘此前互不认识；李慕尘也不知道主角就是当年救下的孩子。主角只能在后期大案中沿事实链查到他，身份揭露不得靠巧遇或旧物一眼相认。

## 5. 景王之网的三层权力节点

### 景王

- 网络最终主人，目标为谋反；长期通过钱、人、渠道、关系和退路积蓄力量。
- 只掌握长期方向、利益目标与关键节点，不亲自处理具体案件、现场执行、下层失误或风险善后。
- 对外温和有礼、愿意施恩；其恩惠真实形成利益关系，也是网络长期运转的一部分。

### 孙玉堂

- 五十岁，景王府管家。年轻时被景王救过一命，追随景王二十多年，因办事可靠成为其最放心的管家。
- 知道景王谋反，负责王府层面的钱、人、外部关系、利益协调、目标传达和善后安排；不负责锦衣卫的正式差事、卷宗权限或东厂具体执行细节。
- 知道廖家灭门是为了清除廖承志调查，参与王府层面的目标、人员和善后安排；不知道现场每名执行者的动作，也不知道李慕尘救走孩子。
- 可直接接触杜文昭，传达王府需要达成的具体目标、时限和需要消除的影响；不替东厂制定侦缉、抓捕和审讯细节。
- 对景王绝对忠诚，必要时愿承担罪责或牺牲性命。其愧疚不会转化为违抗景王。

### 魏承恩

- 锦衣卫内部高层，知道景王是整张网最终主人，并主动为其办事。
- 负责锦衣卫体系内的案件流向、人事安排、差事分配与权限运转；不负责商路和王府账目，也不亲自承担外部执行细节。
- 以职位、权力、保护、利益和上升机会效忠景王，擅长在不同势力间周旋。
- 主线中是中段阶段性假高潮节点。主角作为校尉不能前期频繁或私人化接触他；其存在感应主要由批示、权限后果、旁人反应与制度痕迹建立。

### 杜文昭

- 东厂高层，掌握侦缉、监视、抓捕、审讯与敏感案件处置的实际权力；熟悉文书档案，但不只是档案官。
- 早年受魏承恩提拔，后进入东厂。两人正式职权并非简单上下级，魏承恩仍是其在网络中的主要上层联系人。
- 知道自己替魏承恩与景王府一系办事，也知道存在结党、敛财、排除异己和掩盖案件；不知道景王谋反全貌。
- 对外从东厂职责出发决定侦缉、抓捕、审讯和合法办差形式；不决定景王长期方向，不掌握完整资金链，也不独立定义王府目标。
- 其信念是秩序高于未经控制的真相：要求手下查清事实，却可能决定哪些事实公开、如何归档、谁必须沉默。

### 三人协作边界

- 孙玉堂可以直接联系魏承恩和杜文昭，但联系只传递各自所需的局部目标。
- 魏承恩决定锦衣卫体系内如何使案件、人事和权限向目标倾斜。
- 杜文昭决定东厂内部如何执行侦缉与强制处置，并使行动具有合法外观。
- 三人不能因直接接触而共享完整账目、所有行动细节或景王完整谋反计划。

## 6. 商人层与公开程序

### 沈敬亭

- 商人层节点，利用正常商号、账目与商路替上层处理资金流转。
- 知道自己上面有人，知道自己在参与不透明的关系，但不知道景王是最终主人，也不追问资金最终用途。
- 其继续合作的压力来自家业、家人安全、京城信誉、商路与人脉整套生活可能崩塌，不是单纯贪钱或完全无辜。

### 方正言

- 四十五岁御史，后期负责将可靠事实送入可公开追究的监察程序。
- 前期不与普通校尉主角正面接触。只有主角职位、案件级别、证据和正式程序发展到足够程度后，才能经正式案件或可信上级转介接触。
- 不会因主角的身世、私人痛苦或关系数值而自动提供庇护、弹劾或政治资源。
- 重视证据、人证与递交路径。其谨慎既能保护案件，也可能延误救人和阻止灭口，构成玩家需要面对的现实矛盾。

## 7. 主线揭露约束

- 第一章正面出场范围仅限廖威达、覃保坤、周寒川、冯天顺与案件配角；李慕尘只在序章作为未揭身份的救人者存在。魏承恩、孙玉堂、杜文昭、沈敬亭、方正言与景王不得正面登场。
- 前期碎案各自成立，不能把木牌、商路、东厂、王府或廖家旧案直接焊为一条线。
- 后期玩家通过人物、时间、物件、资金、命令和程序的交叉事实，逐层看见网络；不通过反派自白或一封直指景王的密信完成推理。
- 魏承恩落网后网络仍运转，才证明网络大于单一人物。其替换和接管机制必须在具体案件设计时单独闭合。
