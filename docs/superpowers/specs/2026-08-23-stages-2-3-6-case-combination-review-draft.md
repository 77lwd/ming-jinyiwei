# 第二、三、六阶段案件组合设计：被正确处理的人

日期：2026-08-23  
状态：案件组合基线已获玩家授权采用；已完成两轮子智能体对抗审查  
范围：第二、第三、第六阶段的案件组合、证据因果、权限边界和逻辑自检。不涉及代码、数值、具体章节排期、历史官职定级或终局证据设计。

## 1. 本轮目标与修订原则

这一组案件的核心不是“三起案子都有一张神秘文书”，而是：三桩完全不同的事，先后碰到同一类本不该流出的北镇抚司临时凭照。每一案中，这种凭照造成的直接伤害和被滥用的理由都不同；玩家只有在第三阶段依正式差事核对本百户所自己的凭照总簿，才发现三张凭照并非偶然流出。

这保留“人、物、案卷能被合规流程处理掉”的主题，但避免第二阶段连续出现同一个空白收件栏。第二阶段不出现景王、王府、东厂、魏承恩，也不能让玩家凭一案就知道存在一张网。

以下“临时凭照”是架空明代中北镇抚司内部用于临时押送、查封、夜间通行等短期差事的有编号纸凭。具体名称、形制和制度依据在进入实现前另做资料核验；本稿只固定其叙事功能和证据规则：每张凭照有纸种、编号、当期蜡记和可与总簿核对的副联。前线人只凭纸面、蜡记和编号判断其是否可临时执行，作废状态只在本所总簿中登记，不能被外人随手查到。凭照一经真正规定作废，原纸必须剪角封存；未剪角的真凭照仍足以威吓不敢冒险核验的押役，或被明知内情的受贿者故意放行。

## 2. 第二阶段案件

### 2.1 《雨夜失押》

**差事入口与表层冲突**

货栈护卫马骁是一起货栈斗殴致死案中的关键在场者。死者贺玉持刀威胁在先，地方衙门已将斗殴与死因另行审理；马骁被暂押，是为了等待他就一批账货不符的封箱作证。因该批货涉及北镇抚司正在核查的禁运举报，覃保坤收到有编号的临时押送差牌，派廖威达随押役将马骁转送至指定看押处。

暴雨夜，押役回报马骁在桥头翻车时脱锁逃走。覃保坤正式命廖威达复核“失押”责任：若押役受贿放人，百户所要承担严重后果；若有人持假凭照提走在押证人，则意味着内部凭照已被滥用。

**误判、真相与证据**

最初解释是马骁畏罪脱逃，两个押役收了钱。实际情况是：一张编号真实、用途被篡改的提审凭照在桥头将马骁带走。押役知道交接不合常规，却因对方报得出凭照编号、又以违令相胁，选择伪造“翻车脱逃”掩盖失职。

玩家能逐项验证，而非只听作者说明：锁扣没有从内侧挣开的磨损；车辕的折痕与翻车角度不符；渡头船夫看见一辆有押役同行的篷车离开；一名押役藏在雨披夹层里的交接存根，写有马骁姓名、准确时辰和凭照编号。它证明马骁被带走，不证明是谁下令，也不证明马骁在货栈看见的封箱是什么。

**调查选择与后果**

- 立刻拘押押役：可保住两人互相推诿前的原始口供与存根，但篷车路线会冷掉；
- 暂不公开存根、让一名押役带路：可查到篷车驶往的河埠和一名中转脚夫，但押役会在此后统一口径，责任更难坐实。

两条路线都能完成“失押不是逃脱”的结论，之后给第三阶段留下不同材料：前者是完整交接存根，后者是河埠脚夫记下的凭照编号与领取人的假称。

**结案与遗痕**

本案结清的是失押责任：押役伪报、未按程序核验提审凭照成立；马骁不是自行逃脱。货栈斗殴案和马骁去向没有被假装解决，它们是后续可追问的后果。遗痕是一串真实却不该被用于提审的凭照编号。

### 2.2 《空屋里的嫁妆》

**差事入口与表层冲突**

卢小绫成婚前夜失踪，嫁衣、首饰和钱物都留在房中。她的舅父指控夫家逼走外甥女，夫家则说她跟人私奔。与此同时，百户所接到地方衙门的正式移文：有人曾拿一张写有北镇抚司编号的“临时封验凭”闯入卢宅，要求将房契、嫁妆清单一并封走。覃保坤的差事是核验这张凭照是否出自本所、追回被冒用的凭照与随附文书；失踪案由地方衙门主办，百户所只在凭照冒用与相关证物范围内协办。

**误判、真相与证据**

玩家起初面对的是“新娘私奔还是夫家逼人”的家事解释。调查能推翻它：卢小绫的鞋底有从后院染缸到废染坊的湿靛痕，染坊看门人见过她独自躲入；她藏在嫁衣夹层的父亲手书副契写明小宅归她；舅父欠债簿上有一笔逼近婚期的还款；债主的中人则承认，他拿到过一张带真编号的封验凭，却不知道凭照从何处流出。

卢小绫是为避开舅父借婚事夺契而藏身，舅父为填赌债先制造了夫家逼人的说法。中人只想用凭照制造“官面查封”的压力，逼舅父低价让出债权；他不是网中人，也不知道上层。凭照之所以被人从他手中收回，并非这间宅子本身重要，而是它的编号一旦进入正式核验，就会暴露一张本该已核销的内部凭照仍在流通。

**调查选择与后果**

- 先宣布该凭照失效、强行带走舅父：卢小绫较快脱离控制，舅父却会毁掉债簿，日后只能依副契争产；
- 暗中以凭照编号钓中人：能取得中人收凭照时的交割条和更完整的债簿，但卢小绫必须继续躲藏一夜，且会认为玩家拿她的处境换线索。

**结案与遗痕**

本案结清的是冒用北镇抚司凭照胁迫民宅、舅父借婚事夺契，以及卢小绫的安全去向；房契归属仍由地方衙门按副契和债契处理。遗痕是封验凭的真实编号及中人取得它的时间，不是又一份“去向不明”的房契。

### 2.3 《倒在更鼓前的人》

**差事入口与表层冲突**

城门小吏程佑在换更前被杀，尸旁有赌债票据，债主赵培当晚确曾殴打他。死前经手的临时夜行牌上，却出现了一枚北镇抚司已经核销的编号。城门例行凶案由地方衙门主办；因夜行牌冒用内部编号，覃保坤领到核验编号和查找凭照来源的正式差事，廖威达负责与城门簿、证物逐项比对。地方衙门则在发现被藏起的夜行牌副联和程佑留下的别号后，按凶案程序搜查冯六住处；搜得物证会以清单随案移交，主角不自行入户搜检。

**误判、真相与证据**

赵培是明显嫌疑人，但更鼓、赌坊和换值记录证明他离开后，程佑仍在城门放过一辆篷车。程佑发现篷车所用夜行牌的货载与实物不符，便把夜行牌的副联塞进自己值房的水桶夹层，并在换值簿上写下收钱放车的门军小吏“冯六”的别号。

冯六先收钱替篷车补手续，后到值房取回副联时被程佑撞见，争抢中以门闩击杀程佑。玩家的证据链是：水桶内的副联与被涂改的城门簿页能拼成完整编号；程佑留下的别号对应值班名册；地方衙门依法搜查冯六住处所得的袖口松脂、半张收钱字条与副联撕口吻合；其伤口与门闩血迹相互对应。这样，赵培能被洗脱，冯六的受贿、篡改和杀人也能独立定罪。

**调查选择与后果**

- 先抓冯六：保住人证和车轴松脂，能问出交钱的城外脚夫，却失去跟车机会；
- 先监看冯六：可顺着他找到篷车短暂停靠的空院和货物外包装，但冯六察觉后销毁收钱字条，杀人只能依其他物证推进。

两条路线均不改变冯六有罪，改变的是第三阶段可用的外围材料：人证指向脚夫，或货物外包装留下的发货记号。

**结案与遗痕**

本案结清赵培被冤、冯六行凶及夜行牌被冒用。篷车和货主未必能立即追回，但那张夜行牌的编号进入了百户所需核销的内部凭照记录。

## 3. 第三阶段：第一次串线《失号凭照》

### 正当入口与可验证的连接

三案中出现的真实编号均属于覃保坤百户所应当保管、核销的临时凭照序列。押役为自保提出复核申请，地方衙门就卢宅的冒用凭照发来协查回文，城门案则附有夜行牌副联。三个材料因各自案件而合法进入本所证物袋；覃保坤据此立案调查“已核销凭照为何仍在外流”，并出具调取本所凭照发放总簿、核销簿和封存证物的差牌。廖威达只比较这三份已随案移交的编号与本百户所自有记录，不越级查看民事房契、地方原始档案或其他衙门总档。

玩家从总簿中能确认五件事：

1. 三个编号分别属于押送、封验、夜行三类凭照纸种，出库日相距数月，表面没有连续性；
2. 它们都在出库后极短时间内被同一名库吏标为“错印作废”，正常应连同原纸当日剪角封存；
3. 三张凭照都没有被剪角封存，反而在数月后出现在不同案件现场；
4. 库吏保存的三张领用条，笔迹、日期和经手手印各不相同，不能把他直接写成主谋；但领用条均要求送至同一间内部转收房，且转收房的收件簿缺了对应三页；
5. 覃保坤先以差牌让书记官、库吏共同抄录并盖印总簿页，再封存原簿。之后有人破坏封蜡换走三页，封存记录、先行抄本和缺页位置共同证明总簿遭人动过；它不证明具体是谁动手。

这不是“一样的词出现三次”，而是玩家经合法对照后发现：三张本应毁掉的真实凭照，都经过同一处内部转收房流出。玩家能确认有人利用内部库存为外部人开门，仍不能确认转收房上面是谁、三件事是否服务同一个最终目的，或景王之网是否存在。

### 代价与阶段结果

马骁仍无下落；库吏因害怕和失职选择隐瞒，后被调离；总簿被换页，迫使玩家只能拿着已盖印的抄本继续。玩家并未获得能抓高层的铁证，却第一次推翻“都是地方小人各自作恶”的解释。

## 4. 第六阶段：旧火与现在合拢《旧料行的封存册》

### 受限的调查入口

第四、五阶段已通过独立案件确认：转收房的凭照库存与未结包件由魏承恩掌管的文书权限分配。魏承恩落网后，新的接管人对其辖下所有“已核销、实物却未封存”的临时凭照开展限项清查。这个清查直接来自第三阶段的《失号凭照》案：覃保坤所上交的三张凭照在清单中，廖威达以原案校尉身份奉命核对与这三张同批、同一转收房经手的未结包件。他看到的是一份由差牌列明的有限包件表，不是借魏倒台随意翻十五年前档案。

其中一个未结包件不是十五年前的旧料本身，而是旧料行向转收房交回的“亥四批结清回条”及其附册。火后旧料当年确已入行；按程序，转收房收到回条后应核销该批。由于末页从未签收，这份结清文件一直留作未结包件。附册清楚写明来源为“廖宅火后清点”，并登记“朱漆库牌一，长一尺八寸三分，右下焦裂三叉，左缘双钉孔间距一寸一分，牌面后刨”。这不是玩家找到木牌后才倒推地址，而是一份受限包件中可先读出的来源记录。

### 四段证据链

木牌来自廖宅必须同时满足以下四段，任何一段缺失都不能下结论：

1. **火后转收册**：将批号“亥四”明确标为廖宅火后清点物，并写有木牌的独特尺寸、焦裂方向、钉孔位置与后刨状态；
2. **旧料行出入册**：同一未结包件附有旧料行当年交回的收料回条，确认“亥四”整批入行，木牌未单独转卖；
3. **老余的收料账**：老余保存纸铺修缮杂木的原始收料账，载有从该旧料行购入“亥四余料十二件”的日期、价钱与批号，随后又售给纸铺；
4. **木牌实物与灭门前记录**：纸铺火场保留的木牌精确匹配转收册所列尺寸、右下三叉焦裂和偏位双钉孔；另有廖宅灭门前的木作修缮副单，登记前厅库牌的同样尺寸、朱漆与左缘双钉孔位置。木作副单由承揽工匠的行会留存，独立于北镇抚司的转收册。

四段链条分别回答“来自哪场火”“如何进入旧料行”“如何流到纸铺”“为何确定是廖宅原物”。它们不依赖三岁记忆、知情者口供或单一泛化特征。

### 结论、边界与后果

玩家因此确认：烧焦木牌来自廖宅；廖宅火后清理物曾进入与现案凭照同一转收房。它说明廖承志碰到的是一套能使凭照外流、物件改名、证人失踪、记录被替换的长期机制，而非单一仇家。

这仍不能证明谁下达灭门命令，不能直接推出景王，也不能由一册旧料账替代魏承恩、孙玉堂、杜文昭和最终证据链的后续设计。第六阶段真正的代价有可查事实支撑：清查开始时，覃保坤与接管书记共同签下的包件清单列有十二包；次日，其中三包被一张新出、带同一转收房蜡记的临时凭照领走，签收人只写职号、不写姓名，且该凭照在本所总簿已被标作“错印作废”。清单副本、领出条和总簿核销状态相互对照，证明魏倒台后仍有人能用同一手法调走包件。玩家确认网络可替换，却未能靠这次发现终结它。

## 5. 信息边界

| 节点 | 玩家能确认 | 玩家不能确认 |
|---|---|---|
| 第二阶段 | 三案各自的局部真相；一张真实内部凭照被不当使用 | 三案有共同上层、转收房存在、木牌来源、任何高层姓名 |
| 第三阶段 | 三张不同凭照曾经同一内部转收房，本所总簿遭篡改 | 谁命令转收房、网络全貌、景王谋反、廖宅火案真相 |
| 第六阶段 | 木牌来自廖宅；廖宅火后物件也进入该转收房 | 灭门命令链、景王最终责任、所有执行者身份 |

## 6. 骨架级逻辑自检

- **案件独立性：** 失押责任、凭照胁迫民宅、城门谋杀分别有独立的受害者、直接犯罪者、证据与结案；网络只解释凭照为何流出，不承担三个案件的全部起因。
- **主角权限：** 三案均先由覃保坤获得书面差牌；廖威达只在失押、凭照冒用、编号核验及随案证物范围内行动。卢宅的失踪与房产由地方衙门主办，主角不替其裁判家事与产权。
- **证据来源：** 马骁的转移以押役藏匿存根、渡头目击和车辆痕迹验证；卢案以鞋痕、证人、副契、债簿和中人供述验证；程佑案以藏副联、值簿别号、物证与收钱字条验证。每条核心线索都有保管人、获得路径和可交叉核验的对象。
- **串线强度：** 第二阶段每案只留下自己的编号，玩家没有凭一串数字得到结论。第三阶段在本所总簿中发现“作废却未封存、皆进同一转收房”的可验证共性，才足以推翻偶然解释。
- **木牌来源：** 转收册、旧料行回条、老余账本、木牌实物和木作副单互相限定，既有明确批号也有独特物理特征；其中行会木作副单独立于涉案内部文书，防止单一体系自证。
- **不越级揭底：** 转收房说明的是内部流程节点，不等于魏承恩、王府或景王；魏倒台后的限项清查解释第六阶段的访问权限，且只开放与第三阶段同批未结包件。
