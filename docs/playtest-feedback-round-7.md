# 试玩反馈 Round 7

日期：2026-09-17

## 问题：第一案核验材料不足，口供形成过程不可见

具体位置：第二章第一案《雨夜失押》完成四人闻讯，进入“证据命题核验”工作台后。

玩家反馈：工作台有三道待证问题，每题界面统一要求至少选择三项，但案卷总共只有八项材料，组合空间过小；四名证人的问讯、整理和签押虽然在前一流程完成，最终核验台只出现两项合并后的口供材料，无法看出个人口供如何形成，也无法判断合并记录与原始口供的关系。

## 本轮修复标准

- 六件现场与文书材料保留；
- 周六、赵七、陈老桨、阿顺四份个人签押口供分别成为正式材料；
- 两组口供对照记录在对应两份个人口供签押后形成；
- 第一案最终共有十二件可核验材料；
- 三道命题按论证需要采用不同数量的精确组合，不再统一要求三件；
- 材料卡明确显示材料性质、来源对象和形成步骤，但不提前标出它对应哪一道正确命题；
- 混入无关材料、漏选必要材料或全选仍不能通过。

## 不改动范围

- 不修改第一章；
- 不改变四名证人的既有问讯顺序和逐句对话结构；
- 不提前推进第二案；
- 不新增全局属性、资源或人物关系字段。
