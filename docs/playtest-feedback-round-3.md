# 试玩反馈 Round 3

## 当前反馈

- 玩家认为第一章整体体验不够好，感觉沉浸感不足，推进偏简单、草率。
- 覃保坤的人物特点没有被有效体现，当前更像推动节点的功能角色。
- 本轮优先增强玩家实际“查案”的体验，而不是先做属性或资源展示。
- 第一章独立结案需要同时让玩家感到：确实查清了一宗案，并理解锦衣卫校尉的办案权限与边界。

## 已确认方向

- 覃保坤的人物表现必须遵守既有设计基线：看人、熟悉南城与市井、说话短而具体、办差有火气但不端着，公事上有分寸，必要时替手下承担责任；不得重新发明人物设定。
- 第一章 UI／内容重做的第一优先是查案流程：现场、证物、证词、核验、请示和结果之间要有可感知的因果。
- 属性与资源仍可通过个人档案查看，但不应常驻压过案件主界面。
- 不扩展到第二章、自由行动系统、移动端或其他未确认系统。
