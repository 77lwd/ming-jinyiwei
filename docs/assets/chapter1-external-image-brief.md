# 第一章《纸灰里的银子》外部生图清单

本清单只用于外部图片生成与后续接入。项目不使用内置生图；缺图时必须保留文字流程，不得阻断试玩。

## 统一视觉基线

- 时代：明代崇祯元年，北京城南，写实历史悬疑，不做仙侠、武侠海报或宫廷大片。
- 画面：电影式横向构图，低饱和墨绿、炭黑、灰白纸色，少量朱砂和旧木色。
- 光线：真实火光、阴天余烬、油灯或傍晚自然光；避免霓虹、强金色神光和过度烟雾。
- 人物：廖威达 18 岁，普通锦衣卫校尉，飞鱼服整洁但不威风夸张；覃保坤 38 岁，结实略发福，眼下有疲态，袖口常留洗不掉的墨痕。
- 构图：主体放在画面右侧或中右侧，左侧预留约 35% 安静区域给正文；证物特写需保持清晰边缘。
- 输出建议：桌面主图 16:9，建议 1920×1080 或更高；证物图 4:3 或 1:1；统一人物脸部、服装、发式和色调。

## 生成与验收要求

1. 同一角色至少保持脸型、发式、服装颜色和年龄一致；先生成覃保坤与廖威达角色定妆参考，再批量生成场景。
2. 不要在图中生成现代汉字、UI、印刷水印或难以控制的长文本；案卷文字由游戏界面叠加。
3. 每张图保留正文安全区，不能让关键人物或证物被文字遮挡。
4. 先交付 02、03、05、06 四张核心图即可进行第一轮接入；其余素材可继续用现有文字或旧图过渡。
5. 接入时必须提供真实文件名、尺寸、格式和替代文本；缺图时使用当前节点文字，不得显示破图或空白占位。
