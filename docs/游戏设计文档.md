# 《我在明朝当锦衣卫》游戏设计文档

> 历史素材文档：保留原始剧情文本和早期系统设想，不作为当前运行规则。现行基线以 `docs/superpowers/specs/2026-09-04-full-game-content-baseline.md`、`docs/superpowers/specs/2026-09-05-cross-chapter-state-baseline.md` 和 `docs/superpowers/plans/2026-09-06-final-implementation-plan.md` 为准；当前以电脑端为首要目标。

## 一、游戏概述

### 1.1 游戏类型
文字冒险RPG，复仇题材，古代背景

### 1.2 核心玩法
- 月度行动系统（每月3个行动点）
- 属性养成（武力、智谋、口才、声望）
- 线索收集与调查
- 多结局分支

### 1.3 游戏时长
10年（120个月），约15-20个主线节点

### 1.4 核心体验
- 强烈的代入感和复仇动机
- 策略性的时间管理和资源分配
- 逐层揭开的真相和阴谋
- 选择带来的真实后果

---

## 二、世界观设定

### 2.1 时代背景
大明天启年间（1621-1627），阉党当权，东厂一手遮天

### 2.2 核心事件
15年前（天启六年，1626年），主角家被灭门

### 2.3 游戏开始时间
大明崇祯元年（1628年），主角18岁入职锦衣卫

## 三、主角设定

### 3.1 基本信息
- 姓名：廖威达
- 年龄：18岁（游戏开始）
- 出身：锦衣卫千户之子
- 职位：锦衣卫百户（入职）

### 3.2 背景故事
3岁时，父亲廖承志（锦衣卫千户）因查贪腐案被灭门。
母亲为保护他而死，被剑客李慕尘所救。
养父收养，15年间刻苦练武，考中武举，进入锦衣卫。

### 3.3 复仇动机
- 父母被杀
- 家破人亡
- 唯一目标：查出真相，复仇

### 3.4 初始属性
- 武力：7（养成：刀法基础扎实）
- 智谋：7（养成：观察敏锐）
- 口才：2（性格：沉默寡言）
- 声望：4（身份：新入职百户）
- 财富：30两

## 四、核心NPC

### 4.1 盟友

#### 周寒川
- 身份：锦衣卫千户，廖威达的直属上司
- 年龄：40岁
- 性格：正直、谨慎、有原则
- 关系：父亲的旧同僚，暗中保护廖威达
- 命运：第7-8年被杀（可能可以改变）

#### 冯天顺
- 身份：京营把总
- 年龄：18岁

- 关系：儿时好友，唯一完全信任的人

#### 方正言
- 身份：御史
- 年龄：45岁
- 性格：清廉、刚正、理想主义
- 关系：可以拉拢的政治盟友
- 作用：朝堂力量，弹劾权力

#### 李慕尘
- 身份：天刀门叛徒，隐居剑客
- 年龄：40岁
- 性格：冷漠、矛盾、负罪
- 关系：当年救命恩人，知情者
- 作用：提供关键线索，可能的导师或阻碍

#### 柳如烟
- 身份：花魁/东厂暗探
- 年龄：25岁
- 性格：聪慧、世故、双面
- 关系：情报来源，可能的爱情线
- 作用：提供情报，可能背叛也可能倒戈

#### 孙玉堂
- 身份：景王府管家，商帮幕后掌控者
- 年龄：50岁
- 性格：狡猾、残忍、谨慎
- 关系：父亲案的执行者之一

#### 景王

- 年龄：35岁

- 威胁等级：极高（皇室身份+势力）

9. **皇帝（崇祯）**
   - 领袖：崇祯帝
   - 性质：名义最高权力，实际受限
   - 与主角关系：中立，可利用

## 六、灭门案真相

### 6.1 案件背景
天启年间，阉党当权，东厂横行。
京城商税被大规模贪腐，每年数十万两白银流入景王府和东厂。

### 6.2 案件经过
- 天启六年，廖承志（锦衣卫千户）查到商税贪腐线索
- 他发现祥云商行经手的三十万两巨款流入景王府
- 准备上报皇帝
- 东厂、景王、孙玉堂联手灭口
- 雇佣天刀门杀手灭门
- 李慕尘临时反悔，救下廖威达

### 6.3 核心线索
- 烧焦的木牌："祥云商行"
- 账册残页：三十万两，景王府，孙玉堂经手
- 父亲的半截断刀
- 神秘知情者的帮助

### 6.4 真相层次
1. 表层：家仇（被杀）
2. 中层：商税贪腐（数十万两）
3. 深层：景王谋反准备（积累军费）
4. 终极：朝廷权力斗争（阉党 vs 皇权）

## 七、游戏系统

### 7.1 行动系统

#### 基础规则
- 每月3个行动点
- 每个行动消耗1点（特殊行动可能消耗2点）
- 行动点不能跨月累积
- 不同阶段解锁不同行动选项

#### 行动类型

**公务类**
- 消耗：1点
- 收益：声望、俸禄、上司好感
- 风险：低
- 示例：巡街、办案、守夜

**训练类**
- 消耗：1点
- 收益：属性经验值
- 风险：无
- 示例：练武、读书、学习技能

**社交类**
- 消耗：1点
- 收益：NPC好感、情报、人脉
- 风险：中（可能得罪人）
- 示例：宴请、送礼、拜访

**调查类**
- 消耗：1-2点
- 收益：线索、情报
- 风险：高（可能被发现）
- 示例：跟踪、潜入、打探

**赚钱类**
- 消耗：1点
- 收益：财富
- 风险：中-高
- 示例：接私活、倒卖情报、投资

### 7.2 属性系统

#### 四大核心属性

**武力（0-100）**
- 作用：战斗胜率、威慑力、生存能力
- 提升方式：练武、实战、拜师
- 影响：
  - 20以下：弱鸡，打不过普通混混
  - 20-40：合格，能处理常规战斗
  - 40-60：优秀，锦衣卫中的高手
  - 60-80：一流，江湖好手
  - 80-100：绝顶，天下顶尖

**智谋（0-100）**
- 作用：调查成功率、看穿阴谋、策略选择
- 提升方式：读书、办案、学习
- 影响：
  - 20以下：愚钝，容易被骗
  - 20-40：普通，能处理基本逻辑
  - 40-60：聪慧，能看穿一般阴谋
  - 60-80：智者，运筹帷幄
  - 80-100：诸葛，算无遗策

**口才（0-100）**
- 作用：说服、谈判、社交成功率
- 提升方式：社交活动、学习、实践
- 影响：
  - 20以下：木讷，几乎不会说话
  - 20-40：能基本交流
  - 40-60：能说会道
  - 60-80：舌灿莲花
  - 80-100：纵横家

**声望（0-100）**
- 作用：社会地位、可调动资源、NPC态度
- 提升方式：办案、立功、社交
- 影响：
  - 20以下：无名小卒
  - 20-40：小有名气
  - 40-60：京城名人
  - 60-80：朝野闻名
  - 80-100：权倾朝野

#### 属性成长
- 每次训练获得经验值
- 经验值累积到一定程度，属性+1
- 属性越高，提升越难
- 可以拜师加速成长

### 7.3 资源系统

#### 财富
- 单位：两银子
- 来源：俸禄、办案奖励、私活、投资
- 支出：生活费、送礼、购买装备/情报、贿赂
- 作用：解锁更多行动选项

**财富阶段：**
- <50两：贫困，基本选项
- 50-200两：小康，解锁送礼、情报购买
- 200-500两：富裕，解锁雇人、贿赂、好武器
- 500-2000两：富豪，解锁房产、长期探子、大生意
- >2000两：巨富，解锁豪宅、私人势力、贿赂大员

#### 人脉
- 体现为NPC好感度（0-100）
- 好感60+：可请求帮助
- 好感80+：死党，全力相助
- 好感影响：
  - 提供情报
  - 关键时刻援助
  - 解锁特殊任务
  - 影响结局

#### 线索
- 收集型资源
- 每条线索有清晰度（模糊/清晰/确凿）
- 线索可以组合，推断真相
- 关键线索触发主线节点

### 7.4 技能系统

#### 武学技能
- 刀法、剑法、轻功、内功
- 通过训练或拜师提升
- 影响战斗表现

#### 专业技能
- 侦查、追踪、潜入、审讯
- 通过实践提升
- 影响调查成功率

#### 社交技能
- 说服、威胁、谈判、伪装
- 通过社交活动提升
- 影响社交结果

## 八、开局流程

### 8.1 开场剧情

#### 序幕：15年前的那个夜晚

**场景1：温暖的家**
大明天启六年，京郊廖府。
3岁的廖威达在父母怀中，温暖的家庭场景。

**场景2：突变**
黑衣人突袭，父亲廖承志（锦衣卫千户）奋力抵抗，
被大量黑衣人围攻致死。

**场景3：绝望**
母亲被困暗室，黑衣人破门而入。
李慕尘（天刀门杀手）反水救人，与同伴对抗。
母亲为争取时间，自我牺牲。
李慕尘抱着廖威达逃出，整个宅院被火烧毁。

**场景4：懵懂与恐惧**
3岁的廖威达什么都不懂，只有恐惧和茫然。
李慕尘留下他独自离去。
养父第二天发现并收养。

**场景5：转折（快进15年）**
成长过程：孤僻、刻苦练武、心中只有复仇。
18岁考中武举，进入锦衣卫。

**画面渐黑，15年后**

---

**游戏正式开始：**
大明崇祯元年，北京，锦衣卫北镇抚司。
廖威达，18岁，锦衣卫百户。
今天是入职第一天，也是复仇之路的起点。

### 8.2 新手引导（第1-3月）

#### 第1个月

**任务1：跟随周寒川巡街**
- 教学：盘问、战斗基础
- 遇到小偷，简单战斗
- 奖励：5两

**任务2：了解行动系统**
- 教学：每月3个行动点，如何分配
- 系统提示

**任务3：第一次自由选择**
- 3个行动点自由分配
- 选项：公务（抓逃犯/巡街）、训练（练武）、社交（喝酒）
- 建议至少完成1个公务

**任务4：意外的线索**
- 月末触发
- 整理物品时发现烧焦的木牌："...云...商行..."
- 获得第一条线索
- 系统提示：先站稳脚跟，再慢慢查

#### 第2个月

**自由养成月**
- 无强制任务
- 15-20个行动选项（公务、训练、社交、赚钱）
- 玩家自由选择3个
- 月末可能触发小事件（街头冲突/意外之财）

#### 第3个月

**解锁冯天顺**
- 月初街上偶遇冯天顺（京营把总）
- 解锁社交选项：拜访冯天顺

**如果选择拜访：**
酒馆叙旧，冯天顺察觉廖威达心里有事，
表示"你不是一个人，有难处尽管找我"。
冯天顺好感：0→40（直接跳到友好）

**第3个月结束：**
新手引导完成，系统提示：
"你已经站稳脚跟，从第4个月开始，可以逐步展开自己的计划了..."

### 8.3 动态选项系统

#### 选项解锁机制

**基础选项（永远可用）：**
- 基本公务任务
- 基本训练
- 基本社交

**财富解锁：**
- 50两+：送礼、买普通情报、买普通武器
- 200两+：雇人、贿赂小官、买精良武器
- 500两+：买房产、雇长期探子、贿赂高官
- 2000两+：豪宅、私人势力、贿赂大员

**关系解锁：**
- 周寒川好感60+：传授高级刀法、提供内部情报
- 冯天顺好感60+：帮忙打架、调动军队、借钱
- 方正言好感60+：弹劾、政治庇护

**剧情解锁：**
- 获得线索后：调查相关人物、购买相关情报
- 职位升迁后：调阅更高级档案、指挥手下
- 掌握把柄后：勒索、威胁、交易

## 九、主线剧情节点

### 9.1 第1阶段：立足（1-24月）

**核心：小心试探，初尝甜头，然后碰壁**

#### 节点1：第3月 - 重逢故友（温暖）
- 街上偶遇冯天顺
- 得到第一个真正的盟友
- 情绪：温暖、希望

#### 节点2：第12月 - 祥云商行案（兴奋）

**触发：周寒川交案**
祥云商行账房死亡，死状可疑。

**调查过程：**
1. 去商行调查（3个选择：审讯/找证据/暗中调查）
2. 调查死者背景
   - 死者发现了什么，想去告官
   - 在床板下找到纸条："十五年前，三十万两，景..."
3. 如何结案（关键选择）：
   - A. 如实上报周寒川
     → 周寒川压住案子，好感+10
     → 后续周寒川会暗中保护并提供线索
   - B. 隐瞒纸条，自己留着
     → 独立复仇线，更孤独但更安全
     → 可以自己悄悄调查
   - C. 向魏承恩汇报
     → 纸条被没收，线索断了
     → 魏承恩好感+5，但需要重新找线索

**获得关键线索：景王、三十万两、15年前**

情绪：兴奋、跃跃欲试

#### 节点3：第18月 - 第一次碰壁（挫折）

**详细剧情见前文：**
- 半年暗中调查，蹲守祥云商行
- 追踪马车到孙府
- 被孙玉堂当场抓住
- 孙玉堂提到"你父亲当年也很能干"
- 威胁：停手或死
- 回到住处，收到父亲的半截断刀和威胁信

**情绪：恐惧、挫折、愤怒**

#### 节点4：第24月 - 意外突破（转机）

**详细剧情见前文：**
- 半年僵局，什么都查不到
- 冬天，和冯天顺喝酒解闷
- 夜里，神秘老乞丐送来油纸包
- 包里是账册残页，记录三十万两流向景王府
- 附言："你父亲就是因为查到这个被杀的。小心孙玉堂。——一个想弥补的人"
- 去档案库核实，发现商税被大规模贪腐
- 周寒川找他谈话，警告"水太深"

**获得确凿线索：**
- 商税贪腐
- 孙玉堂经手
- 景王府收款
- 东厂参与

**情绪：震惊、希望复燃**

---

### 9.2 第2阶段：深入（25-60月）

**核心：调查逐步深入，接触到商帮和朝堂势力，敌人开始警觉**

#### 节点5：第30月 - 孙玉堂登门（试探）

---

崇祯三年，九月，秋。

门房来报的时候，你正在磨刀。

刀是父亲留下的那半截——断口齐整，像被人一刀劈断，不像折的，是斩的。你每隔几天就磨一次，不是因为需要，是因为手在动的时候，脑子能停下来。

"百户大人，"门房的声音有点奇怪，低着头，不敢看你，"外头……来了位客人。孙……孙玉堂，说是景王府的管家，说是特来……"

你的手停住了。

*孙玉堂。*

三个字在脑子里沉下去，一圈一圈往深处荡。你在账册残页上看见过这个名字。你在父亲那个已经死去的同僚的文书里见过。你这半年里拼凑的每一条线索，最后都指向同一个地方——祥云商行，那三十万两，景王府，经手人：孙玉堂。

*他来了。*

你深吸一口气，把半截刀放回桌上。

"请进来。"

---

孙玉堂走进院子的时候，你才明白什么叫"最危险的样子"。

你以为会是个凶神恶煞的人，或者至少面色阴沉、气势逼人。你没想到是这个——五十岁的男人，圆脸，微胖，梳着整齐的发髻，穿一件洗得发白的青色直裰，手里捧着个点心匣子，笑着走进来，步子不紧不慢，像走进自己家一样自然。

"廖百户，"他拱手，笑容真诚，眼角都是皱纹，"早就听说了，年轻有为，今日一见，果然一表人才。"

你站起来，回了一礼。你感觉到自己的手指在用力——不是颤抖，是在克制颤抖。

"孙管家大驾，不知有何指教。"

"哎，哪有什么指教，"他摆摆手，把点心匣子往石桌上一放，自己先坐下，"就是路过，讨杯茶喝。你们锦衣卫个个公务繁忙，咱们闲人嘛，有时候就想找个人聊聊天。"

---

茶是你亲手倒的。

你不让下人进来，因为你不相信自己能控制表情，何况控制别人的。倒茶的时候，手是稳的，茶水一滴没洒。

*这双手三岁时攥着母亲的衣角，攥着，攥着，然后什么都没了。*

你把茶推过去。

他接过来，吹了吹，喝了一口，点头道："好茶。"

然后你们聊了起来。聊了半个时辰，聊京城秋天来得早，聊今年西北旱情，聊北镇抚司最近破的几个案子，聊你前途无量。他谈兴极好，声音洪亮，笑声爽朗，是个让人如沐春风的人。

你一直在等。

*等那句真正的话。这种人不会无缘无故登门，就像猫不会无缘无故靠近鸟笼。*

等待是一种折磨。你陪这个人喝茶，说废话，而这个人十五年前雇了刀客杀了你的父亲、杀了你的母亲、烧了你的家，今天坐在你面前，把茶喝得很香。

那半截刀就在你身后的桌上，像一块烧红的炭，烫着你的背。

---

终于，第三盏茶的时候，他随口问：

"听说廖百户最近在查商税的事？"

院子里的风吹过来，卷起几片枯叶，打着旋儿落在地上。

"奉命查了几个走私的小商户，"你说，"都是些不起眼的小案。"

"哦。"他"嗯"了一声，似乎在回味这个答案，然后点了点头，"那就好，那就好。"

他放下茶碗，站起身，拍了拍衣摆，忽然叹了口气，语气里带着一种不明所以的惋惜：

"我这个人哪，记性好，记恩，也记情。当年有位廖千户，和我有过一段缘分，那是个了不起的人，查案的眼光，没得说。"他摇了摇头，"只可惜，太认真了。认真的人，有时候走不远。"

他转头看你。

就那么看着你。

那双眼睛里没有恶意，甚至没有威胁，只有一种很平静的、很温和的审视——像老匠人在看一件新出炉的器物，认真端详，心里已经在盘算，若是打碎了，可惜不可惜，值不值得留。

*我没有动。*

*我坐在那里，感觉那把茶杯烫着掌心，感觉秋风从院墙那边吹进来，感觉这辈子所有的恨都在往喉咙里涌，但我什么都没说。我只是坐着，看他，让他看我。*

"廖百户还年轻，"他最后说，语气像在说一件很可惜的事，"前途无量。"

---

你送他出门。

走到门槛边，他忽然停下来，像是想起了什么，回身把那盒点心塞进你手里。

"带着吃，枣泥的，我家厨子做的，甜。"

然后他上了轿，轿子消失在街角。

---

你站在门口，手里捧着那盒点心。

秋天的风吹过来，吹得巷子里的灯笼轻轻晃了一下。你低头打开盒子，里面整整齐齐摆着八块枣泥糕，每块都切得方正，每块都一模一样，红得像……

你把盒子合上。

*他见过父亲。在父亲死之前，他一定也这样平静地看过他——就是这种眼神，在心里把一个人估个价，算好值不值得留。*

*我母亲最后推我出去的时候，院子里也有风。*

你把点心盒放在地上，转身走回屋里，把门带上。

半截刀还在桌上。你坐下去，把刀拿起来，继续磨。

你什么都没有想。你只是磨刀。

---

**玩家选择：**

- A. **压下去，继续查** — 下月调查继续，风险+1级
- B. **找周寒川汇报** — 周寒川好感+10，获得新线索，但他开始担心你
- C. **找冯天顺喝酒** — 冯天顺察觉异常，主动问你出了什么事
- D. **当夜潜入孙府附近踩点** — 获得情报，但被发现概率大幅提升

#### 节点6：第36月 - 棋子（渗透）

---

崇祯四年，三月，春雨。

你在茶楼坐了三天。

不是因为茶好，是因为祥云商行的账房每隔三天来这里谈一笔账，和同一个人，坐同一张桌，喝同一种茶。这人叫郑九，三十岁，祥云商行外账房，长一张苦瓜脸，烟瘾大，手指熏得发黄。

你查过他的底——父亲是落魄秀才，欠了高利贷，已经催上门了。妻子生了病，二两银子的汤药钱凑不出来。他替孙玉堂管账，月俸一两二钱，不够用，永远不够用。

*一个活在缝隙里的人。*

*这种人有两种用法：捏住，或者递把梯子。*

第三天，你在他身边坐下去，叫了壶热茶，推到他面前。

"郑账房，"你说，"你烟瘾很大，天气一湿就犯，对吧？"

他抬起头看你。那双眼睛里有恐慌，有戒备，有一种认出了锦衣卫飞鱼服的人才有的那种慌乱——这种眼神你见得太多了，它比任何话都诚实。

"廖百户……有何吩咐。"

你把茶碗推近他一些。

"你父亲的债，我替你还了。"

---

安静。

雨打着屋檐，有节奏地落。外头有人在吵架，声音隔着雨听起来很远。

郑九没有动。他只是盯着那碗茶，像在等它开口。

"廖百户……"他的声音低到几乎听不见，"你要什么。"

"不多，"你说，"就是偶尔有个疑问，想找个明白人问问。账上的事，数字的事，有时候看不懂，得有人帮着解释解释。"

他终于抬起眼睛看你。

那双眼睛里有很多东西——恐惧、耻辱、如释重负、还有一种被人看穿之后反而松了口气的奇异感。他在心里算账，你看得出来。他在想这件事值多少，要赔多少，能得多少，最后会是什么下场。

*他没有问我为什么。这种人是聪明的，聪明到知道有些问题不该问。*

"我家里……"他停顿了一下，"我家里的事，廖百户……"

"你妻子的药钱，下个月初一，有人送去。"

他沉默了很长时间。

然后他拿起那碗茶，喝了一口。

---

从这一天起，你有了一颗棋子。

郑九给你的第一条消息，是祥云商行账上有一笔对不上的数——三千两，进账走的是"布匹"，但对方收货方是景王府的一个别院，景王府哪年缺过布？

第二条消息，来的慢一些，是孙玉堂最近频繁接触一个叫卜成的人，东厂的人，崔公公身边的一条狗。

*商帮、王府、东厂——三根线，拧成一根。*

*父亲当年查到的，就是这个。*

你走回住处，把这两条消息写在一张薄纸上，用蜡封好，放进那半截刀旁边的小匣子里。

雨还在下。

---

**玩家选择：**

- A. **继续养着郑九，等更深的消息** — 下个月情报+，但维护成本增加（每月5两）
- B. **顺着"卜成"这条线往下查** — 触发东厂支线，风险大幅上升
- C. **把布匹账目线索交给周寒川** — 周寒川好感+10，他帮你压下风险，但消息可能传出去
- D. **拿着证据去找方正言** — 御史线开启，弹劾可能性+，但动作太早，孙玉堂会察觉

#### 节点7：第42月 - 方正言（联盟）

---

崇祯四年，九月，初秋。

方正言找上你，不是你去找他的。

这件事本身就值得想一想。

他派了个书童，送来一张帖子，说"偶有小叙之意，不知廖百户可有闲暇"。措辞文雅，像是寻常文人的应酬，但落款旁边加了一行小字："已知祥云商行事，亦知廖百户之意。"

*他知道了。*

*消息是怎么传出去的？郑九还是周寒川那边漏了风声？还是这个御史有自己的渠道？*

你去赴约的时候，带了刀。

---

方正言住在一条僻静的胡同里，宅子不大，院子里种了几棵竹，雨后还挂着水珠，竹叶的颜色很深，像墨泼上去的。书房里坐着个五十岁左右的男人，清瘦，胡须修整，穿一件半旧的青袍，正在磨墨，见你进来，放下墨锭，站起来行礼。

"廖百户，请坐。"

你坐下来，看他。

他这个人，和孙玉堂是两种人。孙玉堂身上有一种向内收的危险，像水面下的石头，看不见，踩上去才知道。方正言身上是一种向外的力——是那种读了太多书、认死理、会为了一件事硬抗到底的人，这种人也有危险，但危险是明的，不是藏着的。

"你知道什么。"你没拐弯。

他也没拐弯。

"祥云商行过账景王府的那笔布匹钱，"他说，"三千两，是今年三月的事。我有一个学生，在户部行走，偶尔帮我留意一些账目往来。廖百户在查商税，我在查田税——殊途，但同归。"

*同归。他在说一件大事，他知道他在说什么，他不怕。*

*这种人好用，也容易死。*

"你想怎样，"你问，"弹劾？"

他沉默了一下，然后说："现在弹劾，没有用。景王的案底一张都没有，崔公公在司礼监，弹章到不了皇上手里就会消失。我需要的是实证——账册，款项流向，具体的数字，经手人画押过的东西。"他顿了顿，"我听说廖百户手里有线索。"

"你听说得不准，"你说，"我手里有的是半个线索。"

"半个够了，"他平静地说，"再加上我这半个，可以拼出一个完整的账目脉络。"

---

你们谈了一个时辰。

出门的时候，竹叶上的水珠已经落尽了，秋风吹干了，午后的日头斜斜照进来，把竹影打在地上，细细长长的。

*他是条直线，我是条弯路。直线快，弯路活。把这两条线绑在一起，不一定好走，但有些门，只有他能开。*

你往回走，走了半条街，停下来。

身后有人在跟着。不是孙玉堂的人，步子太生，离得太远——是个生手，或者是个故意让你发现的熟手。

你没有回头，继续走。

*先记住，再说。*

---

**玩家选择：**

- A. **答应与方正言合作，共享现有线索** — 御史线正式开启，弹劾力量+，但风险扩散
- B. **缓着，只谈不给** — 维持联系但保留底牌，方正言好感-5，但主动权在你
- C. **回头抓住跟踪者** — 调查是谁在监视，可能得到新情报，也可能打草惊蛇
- D. **去查方正言背景** — 先确认他的可靠性，延迟一个月再决定

### 9.3 第3阶段：危机（61-84月）

**核心：关键NPC牺牲，真相揭开一部分，你被敌人盯上，撕破脸**

#### 节点11：第66月 - 李慕尘（真相碎片）

---

崇祯六年，九月，山野。

你找了他三个月。

没有人知道李慕尘在哪里，或者说，知道的人不愿意开口。你沿着当年的线索往外找——天刀门旧址，废弃的驿站，山西道上的几个小镇。最后是一个卖草药的老头给了你一个地名，顺嘴说的，也许没想到你会去。

他住在山里，一间石屋，半亩菜地，门口放着一把剑。

你站在门口，等了一刻钟，没人来开门。

"李慕尘，"你说，"我是廖承志的儿子。"

安静。

然后门开了。

---

他比你想象的要老。四十岁，但看起来像五十，头发半白，眼睛里有一种很深的、很久的疲倦。他看见你，看了很长时间，不说话，像是在你脸上找什么东西。

"进来。"

屋里很简单，一张桌，两把椅，没有多余的东西。他给你倒了水，坐下来，两手放在桌上，看着你。

"你来问什么，"他说，"问我为什么当年没杀你，还是问我为什么杀了你父亲。"

*都问。*

"都问，"你说。

他沉默了很长时间。

"我没杀你父亲，"他最后说，"是另外两个人动的手。我当时的任务是……"他停顿，"是清理痕迹。"他看着自己的手，"你母亲，也不是我。"

*我知道，"他说，"所以你救了我。"*

"不是因为那个，"他摇头，"你那时候三岁。你坐在院子中间，地上全是血，你不哭，你就坐在那里，眼睛睁得很大，看着火，看着我。"

他停住了。

"我没法动手，"他说，"就是没法。"

---

他告诉你的，比你知道的多了一层。

当年的案子，东厂是执行方，景王是金主，但有一个人是他们都不愿意提起的——有人在皇上面前进言，促成了那道密令，让锦衣卫内部"自行处理"廖承志的案子。那个人现在还在，职位已经不是当年那个了，但人还在。

"谁，"你问。

他说了一个名字。

不是孙玉堂，不是魏承恩，不是崔公公。

是一个你认识的人。

---

---

你走出石屋的时候，日头已经西沉了，山里冷，风从沟里来，吹得人眼睛发酸。

你没有回头。

*六年。查了六年。最后查出来的，是一张我以为熟悉的脸。*

#### 节点12：第72月 - 周寒川之死（代价）

---

崇祯七年，三月，夜雨。

周寒川死在一个普通的夜里。

不是被人暗杀，不是在街上，是在自己家里，说是突发急病，心疾。郎中来得太晚，已经回天乏术。你赶到的时候，他已经停了气，躺在床上，脸色很平静，像是睡着了。

他的夫人在哭，他的儿子跪在旁边，都不说话。

你站在门口。

*心疾。*

*六十岁的人，确实会死于心疾。但六十岁的人也可以被人一碗汤送走，让郎中看不出来。*

你留下来帮着料理了三天，搜遍了他的书房——找到了一封没发出去的信，写给你的，墨迹还新，最后一句话没写完：

"威达，我一直知道你父亲的案子，我当年选择了沉默，是因为——"

后面空着。

*他死在那个破折号后面。*

---

你把那封信收好，走出周府，站在雨里。

冯天顺从后面追上来，撑着伞，把伞举到你头顶，什么话都没说。

你们就那么站着，站了很长时间。

"下一步，"冯天顺最后说，"怎么走？"

你抬头，看着雨。

*下一步。*

*我已经失去了父亲、母亲、郑九，现在是周寒川。每失去一个人，这条路就往前走了一段——用别人的命换的路，我没有资格回头。*

"继续，"你说。

崇祯五年，三月，夜。

你第一次见柳如烟，是在一场不得不去的宴席上。

魏承恩请客，说是给几个千户百户接风，地点在教坊司附近最好的那家院子。你去了，坐在末席，端着酒杯，一口没喝，看着上头那些人推杯换盏，声音越来越大。

*这种酒局你最厌恶。每个人的眼睛都在算计别人，嘴里说的全是废话，废话里藏的才是刀。*

然后她走进来。

弹琵琶的，穿一件烟色的衣裳，发间只插了一支素簪。你原本没太注意，人在这种场合眼睛会自动钝掉，只接收有用的信息。但她落座之后，调了两下弦，抬眼扫了一圈座中人，目光在你脸上停了不到一息——只是那一下，不多，不少，精准得像一把刀在量你的尺寸。

你继续看别处。

*她知道我在哪里。我来之前，她就知道了。*

---

宴散，她叫人给你递了个东西——一张纸条，折成小方块，裹在一片茶叶里，放在茶盏底下。

你打开来看。

上面只有一行字："廖百户查的那条线，往西走，不往东。"

你把纸条烧掉。

第二天，你按着那句话换了方向，去查孙玉堂在西城的一处货栈，结果在那里找到了一批不在账上的皮货——走私货，规模不大，但能证明祥云商行在内账之外另有一套账目体系。

*她给的消息是真的。*

*但真消息未必出于真心。*

你花了三天查柳如烟的底——花魁，二十五岁，本名不详，四年前从扬州来京，会弹琵琶，会说话，很快成了教坊司里最炙手可热的人。和她来往的人里有东厂番役，有锦衣卫，有言官，有商贾——她像一块磁石，什么铁屑都往她身上贴。

东厂的人。

*这条线是她给的，也可能是崔公公要她给的。引我往某个方向走，或者探我手里有什么。*

*但消息是真的。真消息可以是陷阱，也可以是真心。*

你暂时没有答案。

---

**玩家选择：**

- A. **主动接触柳如烟，摸清她的底牌** — 情报线开启，但东厂警觉度+
- B. **暗中调查她的来历** — 延迟一个月，获得她背景线索
- C. **拒绝接触，保持距离** — 安全，但放弃情报渠道
- D. **反过来利用她，故意传假消息** — 高风险高回报，需要智谋60+

---

#### 节点9：第54月 - 魏承恩施压（内部危机）

---

崇祯五年，九月，秋末。

魏承恩把你叫进去，不是在公堂，在他的后院书房。

这件事本身就是个信号。公堂谈的是公事，后院谈的是别的。

书房布置得很雅，字画、古玩、名家手迹，处处透着"我是个有品味的人"的意思。魏承恩坐在太师椅里，五十五岁，圆润，头发梳得一丝不乱，见你进来，让你坐，亲手倒了茶，递过来，脸上带着一种很熟练的温厚笑容。

你接过茶。

*这个笑容练了几十年了。进东厂之前练的，大概。*

"威达，"他用了你的名字，不是官称，"坐了五年了，干得不错。我一直看着你，心里高兴。"

"谢指挥使大人抬爱。"

"也不是抬爱，"他摆摆手，"是实话。就是……"他停顿了一下，看了看茶碗，若有所思，"就是有些事，我想跟你说说，当长辈的，也是个提醒。"

你等着。

"最近有人跟我说，你在查一些……"他选词，"范围有点广的事。商税、王府，这些，水太深。当年你父亲，"他叹了口气，"就是……唉，年轻人啊，忠心可嘉，但要懂得审时度势。"

*他提父亲。*

*提父亲，是警告，也是炫耀——他知道当年发生了什么，他希望你知道他知道。*

你把茶碗放下。

"指挥使大人说的是，属下年轻，有时候不懂轻重。承蒙大人提点，定当谨记。"

他满意地点了点头，和你又聊了几句家常，让你离开。

你出门，走了三步，听见身后书房的门合上了，隔着门传来一点细微的声音——不是说话，是翻东西。在翻什么？他在记什么？

*他在等我犯错，还是他已经有我的把柄了？*

回到住处，你发现桌上的东西被动过了——不多，只有一点点，摆放的位置偏了不到一指宽。

那个小匣子还在，刀还在，但里面叠放纸张的顺序反了。

*有人来查过了。*

---

**玩家选择：**

- A. **装作不知，继续暗中行动** — 维持现状，但风险持续累积
- B. **找周寒川商量对策** — 周寒川好感+10，他帮你设了个反侦察的局
- C. **把重要线索转移藏匿** — 安全，但需要花费2个行动点
- D. **主动去魏承恩那里示弱，递一个小把柄安抚他** — 风险暂时降低，但欠了人情

---

#### 节点10：第60月 - 第一次亮刀（转折）

---

崇祯六年，三月，深夜。

这一夜出了事。

郑九死了。

消息是天亮前来的，说是喝酒失足落水，在积水潭边找到的，已经凉了。你站在那条消息前，手里还拿着那张纸，纸上的字墨迹新鲜，还带着墨香。

*失足落水。*

*三月，天还冷，他这半年滴酒不沾，我给的钱够他过日子，他父亲的债已经还了，他有理由活下去，没有理由去喝酒。*

你把那张纸折起来。

他是你的棋子，但他也是个活人——苦瓜脸，烟瘾大，有个生病的妻子，算了一辈子别人的账，最后被人把自己的账算清了。

---

你去看现场。积水潭边，官差已经走了，只剩一块被踩乱了的泥地，还有水边一只落单的鞋。那只鞋放得太整齐，不像是落水前踢掉的，像是有人放上去的。

*他们知道郑九跟我有往来。他们杀人，是给我看的。*

*这是个信号：我们动手了，你看见了，下一个轮到谁，你想清楚。*

你在那里站了一会儿，看着水面。

然后你意识到——已经五年了。五年，你查到了多少？商帮的账，王府的线，东厂的影子，御史的盟友，一条条线都在你手里，但没有一条线够粗，够用来收网。

而另一边：孙玉堂知道你，魏承恩知道你，东厂开始盯你，你的线人死了。

*继续这样下去，早晚轮到我。*

*要变了。*

你转身，走回北镇抚司，去找周寒川，把五年来收集的所有线索，第一次，完整地摊在了他面前。

周寒川听完，沉默了很长时间。

最后他说："这条路，从你父亲的时候我就知道通向哪里。我拦过你，你没听。"他看着你，"现在，你准备走到哪一步？"

你答："我准备走到底。"

他又沉默了一会儿。

"好，"他最后说，"那我陪你走。但威达，要走到底——就要做好失去一切的准备。"

---

**第2阶段终章——进入第3阶段，危机开始**

**玩家选择（影响第3阶段开局方向）：**

- A. **先稳住，用三个月重新布局，找新线人** — 稳健，但孙玉堂已开始下一步
- B. **立刻联合方正言发起弹劾** — 激进，可能触发提前摊牌
- C. **去找李慕尘** — 解锁隐藏线索，代价：必须面对当年真相
- D. **去查柳如烟，确认她的立场** — 可能获得东厂内线

### 9.4 第4阶段：终局（85-120月）

**核心：开始主动反击，扳倒敌人，最终对决**

#### 节点13：第90月 - 收网前夜（谋划）

---

崇祯八年，九月。

你已经不是六年前那个百户了。

千户，锦衣卫北镇抚司实授千户，手底下有人，有档案权限，有可以合法查阅的东西。声望积累到能让某些人不得不递名片的程度，财富攒到不再为银子发愁的程度，方正言的弹章已经写好了三份，就等一个合适的时机。

你把所有的线拿出来，一条一条摆在桌上。

商税贪腐——有账目，有经手人郑九的遗书（你早就让他写了一份，就是为了这一天），有景王府收款的旁证。

天刀门灭门案——有李慕尘的证词，虽然他未必肯上堂，但证词在你手里。

当年进言的那个人——证据还不够，但够用来威胁。

东厂——这条线最难，崔公公后面有皇权的影子，不能硬碰，只能围。

*七年。*

*七年了，这些线终于够长了。*

冯天顺坐在对面，把刀放在腿上，听你说完，然后问："我要做什么。"

你告诉他。

他想了想，点头："行，打架这事交给我，别的我不懂。"

---

**玩家选择（决定终局策略方向）：**

- A. **先扳孙玉堂，再向上推** — 稳扎稳打，但给景王和东厂时间反应
- B. **三线并进：商帮+弹劾+御前告状** — 激进，需要极高的资源和人脉储备
- C. **利用柳如烟，从内部瓦解东厂** — 需要柳如烟已倒向你一边
- D. **找皇帝** — 险棋，需要确凿证据和极高声望（80+）

---

#### 节点14：第102月 - 孙玉堂落网（前半段清算）

---

崇祯九年，三月。

孙玉堂被捕的那天，你站在他家门口，看着他被带出来。

他还是那个样子，圆脸，微胖，穿着那件青色直裰，手被锁住了，但步子还是不紧不慢。他经过你身边的时候，抬头看了你一眼。

那双眼睛里没有恐惧，也没有仇恨。只有一种——你想了很久，才找到词——只有一种认可。像是见到了一件终于成型的器物，点了点头，说：好，可以了。

"廖千户，"他说，声音不大，"你父亲，当年也是这么站着的。"

你没有说话。

他被带走了。

---

*我等了十九年。*

*他被带走的那一刻，我以为会感觉到什么——解脱，或者欢喜，或者泪水，什么都行。*

*什么都没有。*

*只是还有下面的人没动，这件事还没完。*

你转身，回到北镇抚司，继续写那份奏疏。

---

**玩家选择：**

- A. **趁势弹劾魏承恩** — 锦衣卫内部清洗，风险中，需要周寒川遗物作为证据
- B. **转向景王** — 直接攻击最大目标，风险极高
- C. **先稳住，等孙玉堂招供** — 从孙玉堂口中得到指向景王和东厂的证词

---

#### 节点15：第114月 - 最终对决（终章）

---

崇祯十年，九月。

景王被削藩，崔公公被下狱，魏承恩致仕，天刀门门主被捕——这些事情发生在一年之内，有些是你推动的，有些是被你的行动带起来的多米诺骨牌。

但最后一件事，只有你能做。

李慕尘找上你，说当年亲自杀死你父亲的那个人，现在就在京城，换了个名字，换了个身份，还活着。

你花了三天找到了他。

他住在一条普通的胡同里，是个普通的中年人，开着一个小铺子，过着普通的日子。

你站在他铺子外面，看着他在里面做生意，和顾客笑着说话，找零，道谢，送客。

*这就是杀死父亲的那双手。*

---

**终局选择（决定结局方向）：**

- A. **用法度解决——移交审讯，明正典刑** → 正义结局
- B. **亲手了结** → 复仇结局（不同条件下有不同后果）
- C. **放他走，因为已经够了** → 放下结局
- D. **用他作为最后一枚棋子，换取更大的清算** → 谋略结局

## 十、结局系统

### 10.1 结局框架

结局由三个维度决定：**复仇方式**（法度/私刑/放下/谋略）、**代价**（失去了谁、付出了什么）、**身后事**（你在这个世界里留下了什么）。

共12个主要结局，根据前期积累的选择动态组合。

---

### 10.2 主要结局

#### 结局一：明正典刑（正义结局）

条件：声望70+，方正言存活，选择移交审讯

景王被削、崔公公被斩、孙玉堂秋后问斩，所有经手人明正典刑，案子被记入实录。你父亲的名誉得到平反，廖承志，锦衣卫千户，忠义之士，这几个字写进了档案里。

你从北镇抚司走出来，是个三十岁的人。十年，结束了。

但没有什么特别的感觉。正义到来的时候，和你想象的不一样——没有雷霆，没有光，只是一些官吏在走程序，一些文书在盖印，一些人被带走，一些事被记录在案，仅此而已。

冯天顺在门口等你，拍了拍你的肩膀，说："走，吃饭去。"

你跟他走了。

---

#### 结局二：复仇之刃（私刑结局A — 亲手了结，后果：流亡）

条件：武力60+，选择亲手了结，事后证据不足以保全

你杀了他。

走出那条胡同的时候，手上还有血，你在墙根擦了擦，走进人群，消失了。

锦衣卫后来立了通缉文书，画像画得不太像，但还是像。冯天顺替你拖延了三天，方正言说他什么都不知道，柳如烟给了你一条出城的路。

你出了京城，往南走，走得很远。

有时候在某个地方停下来，看着天，想那个胡同，想那双手，想父亲的脸——其实已经记不清了，只记得那把断刀和那个夜晚的火光。

够了。

---

#### 结局三：复仇之刃（私刑结局B — 亲手了结，后果：成仁）

条件：武力60+，选择亲手了结，随后主动投案

你杀了他，然后去北镇抚司自首。

审讯很长，判决很重，但方正言在朝堂上替你说话，冯天顺在外面闹，柳如烟把一些不该出现在公堂上的证词送进去了。

最后判了流放。

启程那天，冯天顺送你到城外，把自己的刀塞给你，说"路上防身"。你把刀推回去，说你有。

父亲那把半截断刀，缺了一截，但还能用。

---

#### 结局四：放下（释怀结局）

条件：任意时间，选择放他走

你看着他在铺子里做生意，站了很长时间，然后转身走了。

没有人知道你去过那里，没有人知道你做了这个决定。

你回到北镇抚司，继续做你的千户，继续查案，继续活着。那个名字在你脑子里放了很多年，慢慢地，像一块石头被水泡久了，棱角磨掉了，还在，但不那么硌人了。

这不是原谅。你没有原谅任何人。

你只是决定，不让仇恨再花你更多的时间了。

---

#### 结局五：以棋了棋（谋略结局）

条件：智谋70+，柳如烟已倒向你，选择利用最后一枚棋子

你用那个人换了景王最后一批证据——他知道一些你不知道的事，知道景王谋反的最后一块拼图。你拿这个换了他的命：他离开京城，你得到证据。

景王伏法，案子彻底清查，你父亲的名字写进史册。

那个人去了哪里，你不知道，也不想知道。有些账，不是每一笔都能还清的；有些棋子，用完了就放手，这才是下棋。

冯天顺说你变了，变得和过去不像。你说："是吗。"

也许是，也许不是，也许每个人走到最后都会变成这样的人。

---

#### 结局六：未竟（悲剧结局）

条件：前期失误积累过多，周寒川死、冯天顺死或重伤、方正言被打压

你赢了，但赢得太惨了。

景王和崔公公被扳倒，孙玉堂伏法，案子清查，父亲的名誉恢复——所有该完成的事情都完成了。

但站在最后那一天，你身边已经没有人了。冯天顺走了（或者残了），方正言被贬谪，周寒川早就不在了，郑九早就不在了。

复仇完成了，但这条路上，你把能失去的人都失去了。

你站在那里，是个三十岁的人，什么都有，什么都没有。

---

#### 结局七：折戟（失败结局）

条件：某个关键节点选择失误，提前被敌人抓住

这条路没有走到底。

也许是在第四年，也许是在第七年——某个夜晚，某条巷子，某个你以为安全的地方，事情就这样结束了。

结局是死，或者是一种比死更长的结束——流放，或者被废，或者消失在某个不知名的地方，没有人知道，没有人记得。

廖承志的案子，还埋在档案库里。

---

### 10.3 隐藏结局

#### 隐藏结局一：天刀门门主（武力路线极致）

条件：武力90+，加入或征服天刀门，走纯武力路线

你用刀解决了一切。

最后成了天刀门的门主，或者彻底剿灭了天刀门——取决于前期选择。案子清查，但你站在一个很奇异的位置上：既是锦衣卫，也是江湖人，两边都用得上你，两边都不完全是你的地方。

李慕尘最后对你说了一句话："你比你父亲更像一把刀。"

你不知道这是不是夸奖。

---

#### 隐藏结局二：权倾一时（声望路线极致）

条件：声望90+，口才80+，走政治路线到极致

复仇是手段，权力是结果。

案子清查，仇人伏法，你成了锦衣卫指挥使，坐到了魏承恩曾经坐的那把椅子上。

有一天你看着镜子，想了很久，想不起来自己当初究竟是为了什么走上这条路。

然后你想起来了，然后你放下镜子，继续处理公务。

### 11.2 核心数据结构

```typescript
// 游戏状态
interface GameState {
  month: number;          // 当前月份 1-120
  phase: 1 | 2 | 3 | 4;  // 当前阶段
  attributes: {
    wuli: number;         // 武力 0-100
    zhimou: number;       // 智谋 0-100
    koucai: number;       // 口才 0-100
    shengwang: number;    // 声望 0-100
  };
  wealth: number;         // 财富（两）
  actionPoints: number;   // 当月剩余行动点 0-3
  clues: Clue[];          // 已收集线索
  npcRelations: Record<NpcId, number>; // NPC好感度
  riskLevel: 1 | 2 | 3 | 4 | 5;      // 当前风险等级
  flags: Record<string, boolean>;      // 剧情开关
}

// 行动选项
interface Action {
  id: string;
  label: string;
  cost: number;           // 行动点消耗
  condition?: Condition;  // 解锁条件
  effects: Effect[];      // 执行效果
  narrative?: string;     // 执行时的叙事文本
}

// 主线节点
interface StoryNode {
  id: string;
  month: number;
  title: string;
  narrative: string;      // 主叙事文本
  choices: Choice[];      // 玩家选择
  trigger: Condition;     // 触发条件
}
```

### 11.3 界面布局

**主界面三栏：**
- 左栏：状态面板（月份、属性、财富、风险等级）
- 中栏：叙事区域（主文本，古书卷轴风格）
- 右栏：行动选择（当月可用行动列表）

**视觉风格：**
- 背景：深墨色或宣纸色，可切换
- 字体：衬线字体，主文本较大，旁白较小
- 内心独白：斜体，颜色略浅
- 过场动画：页面切换淡入淡出，节点过场用墨迹扩散效果

### 11.4 存档系统

- 自动存档：每次行动后自动保存到 localStorage
- 单存档：不支持多存档，不支持手动回档
