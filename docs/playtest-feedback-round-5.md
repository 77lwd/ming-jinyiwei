# 试玩反馈 Round 5

日期：2026-09-10

## 玩家反馈

在第一章纸铺火案的第一日调查中，玩家选择一条调查路线后，界面曾再次呈现同一层级的调查方向，形成重复选择和伪循环。玩家无法确认第一次选择是否产生了实际办案进展。

## 问题定位

旧实现只记录 `activeRouteId`，没有在首次选择路线时完成该路线的第一项查验动作，因此确认结果后只是切换节点，没有新增材料。

## 本轮修复

- 首次选择路线立即完成该路线的第一项查验；
- 第一项材料立即写入案情记录；
- 下一步只显示该路线的后续查验动作；
- 完成后才回到剩余调查路线；
- 第二日补查完成后回到第二日核验，不回到第一日；
- 增加回归测试，禁止同一调查方向重复出现在下一步。

## 验收标准

- 选择“核验送样路线”后，下一步只出现“找脚夫核对”；
- 不再出现“核验送样路线”本身；
- 送样路线完成后只出现另外两条未完成路线；
- 第二日补查完成后回到第二日核验。
