# 第一章《纸灰里的银子》可玩性 Critique

日期：2026-09-09  
范围：当前已接入的第一章实际流程、`src/data/chapter1.ts` 与既定第一章玩法设计。  
状态：问题审查，暂不进入代码实现。

## 结论

当前第一章“能通关”，但还没有形成可玩性意义上的查案循环。玩家主要是在多个预写结果之间选择阅读顺序；证据、人物反应、时间压力和结案判断没有真正由玩家操作产生。

因此，Task 4 的 UI 接入可以视为完成了可运行切片，但第一章的可玩性验收尚未通过。第二章及后续章节继续冻结。

## 当前实际流程

1. 进入纸铺现场，阅读吴生被指控的背景。
2. 三选一：送样路线、火场、客户副联。
3. 无论选择什么，进入同一个“三处矛盾”节点，并一次性获得三类关键事实。
4. 夜间三选一：整理、看吴生、守残料。
5. 无论选择什么，进入同一个第二日核验节点，并一次性获得完整时间线。
6. 二选一：当众复核或暂不点破。
7. 自动结案、木牌入档、冯天顺重逢。

## 核心问题

### P0：选择没有改变信息获取

三条调查入口的结果都汇入同一节点，玩家没有机会因为先查某处而获得独特证词、错过窗口或改变后续压力。选择标签不同，实际玩法相同。

### P0：证据没有被玩家核验

“假地址、火场位置、客户副联、纤维、结法、数量缺口”由叙事一次性宣布。玩家不需要把证据与说法配对，也不需要判断哪一项足以支持下一步。

### P0：结案不是玩家判断的结果

第二日两个选项只是两种文字演出，任一选择都会直接进入结案。没有“提交事实判断＋关键依据＋处置建议”的玩家操作，因此缺少查案完成感。

### P1：覃保坤仍偏功能角色

覃保坤会提醒程序边界，但主要作用仍是解释规则和把玩家送往下一节点。他没有根据玩家的办案顺序、证据质量或对人的态度作出具体反应，也没有通过短促、具体的现场判断展示其“看人、熟悉南城、有火气但有分寸”的特点。

### P1：锦衣卫身份没有转化为玩法

权限限制被文字说明表达出来，却没有变成玩家可操作的“查访、勘验、请示、封存”流程。玩家知道自己不能越权，但没有感受到自己如何在权限内推进案件。

### P1：压力与代价没有落到当前状态

设计要求夜间选择改变健康、银两、证物稳定性或吴生信任；当前三个结果主要是不同段落文字，缺少可观察的后续差异。

### P1：案件矛盾缺少逐步升级

玩家一进入“三处矛盾”就得到完整真相链，悬念从“吴生是否被冤枉”直接跳到“贺兴如何作案”，中间没有怀疑形成、被反驳、再修正的过程。

### P2：重玩价值很低

由于所有调查路径最终汇合，重玩只会更换几段结果文案，无法比较不同办案策略的证据完整度、人物态度或结案质量。

## 可玩性评分（当前基线）

| 维度 | 分数 | 说明 |
|---|---:|---|
| 玩家目标清晰度 | 3/5 | 知道要查火案，但不知道每一步要证明什么 |
| 选择意义 | 1/5 | 入口不同，结果基本相同 |
| 信息不确定性 | 1/5 | 关键事实被直接告知 |
| 证据操作性 | 1/5 | 证据只能阅读，不能比对或组合 |
| 推理满足感 | 1/5 | 结论由文本宣布，不由玩家提交 |
| 人物互动 | 2/5 | 有覃保坤和吴生，但反应不随行为变化 |
| 锦衣卫职业感 | 2/5 | 有权限说明，缺少权限内操作 |
| 压力与代价 | 1/5 | 夜间取舍没有足够可感知后果 |
| 节奏与悬念 | 2/5 | 场景顺序清楚，但转折过快 |
| 重玩价值 | 1/5 | 路线汇合，策略差异很小 |
| **总分** | **15/50** | **未通过可玩性门禁** |

## 必须保留

- 纸铺案独立结案；
- 吴生洗脱嫌疑、贺兴被移交；
- 烧焦木牌只作为独立异常物入档；
- 第一章不提前引入后续人物、李慕尘真实身份、廖家旧案真相或景王；
- 覃保坤的权限边界不变，廖威达不越权；
- 两日主案结构，不新增自由行动窗口或风险系统。

## 下一轮改造目标

把流程改造成：

`现场观察 → 选择调查手段 → 获得局部证据 → 对照口供/物证 → 请示覃保坤 → 形成怀疑 → 第二日验证 → 提交结案判断`

下一步应先设计两到三个可玩性方案，再由玩家确认；确认后先写玩法规格和测试，再改数据与流程。暂不修改 UI 或进入第二章。
